## 第 1 章：面向对象程序设计概述

### 1.1 OOP 核心概念

| 概念 | 说明 | 关键字 |
|------|------|--------|
| **类 (Class)** | 对一类事物的抽象描述 | `class` / `struct` |
| **对象 (Object)** | 类的具体实例 | 实例化 |
| **封装 (Encapsulation)** | 将数据和操作封装在类内，通过访问控制隐藏细节 | `public` / `private` / `protected` |
| **继承 (Inheritance)** | 派生类继承基类的成员，实现代码复用 | `:` |
| **多态 (Polymorphism)** | 同一接口，多种实现（编译时 + 运行时） | 重载 / 虚函数 |
| **抽象 (Abstraction)** | 忽略次要特征，提取共性本质 | 纯虚函数 |
| **消息 (Message)** | 对象之间发出的行为请求 | 函数调用 |

**面向对象方法的基本思想：** 模拟人类习惯的解题方法，将问题分解为对象，通过对象之间的消息传递完成功能。

**面向过程 vs 面向对象：**

| 对比维度 | 面向过程 | 面向对象 |
|----------|---------|---------|
| 基本单元 | 函数 | 对象/类 |
| 分解方式 | 功能分解（自顶向下，逐步求精） | 对象分解 |
| 数据地位 | 从属于函数 | 数据 + 操作一体 |
| 程序结构 | 算法 + 数据结构 | 对象/类 + 对象/类 + ... |
| 典型语言 | C | C++、Java |

### 1.2 C++ 对 C 的扩充

#### 1.2.1 const 关键字

**const 与指针的三种结合：**

```cpp
const int *p;      // (1) 指向常量的指针：不能通过 p 修改指向的值，p 可指向别处
int *const p;      // (2) 常量指针：p 不能指向别处，但可通过 p 修改值
const int *const p;// (3) 两者都不可修改

// 记忆法：const 在 * 左边 → 修饰值；const 在 * 右边 → 修饰指针
```

**const 修饰函数：**
- `void func(const int x);` — 参数为 const（函数内不能修改）
- `const int* func();` — 返回值是指向常量的指针
- `void func() const;` — **常成员函数**：函数体内不能修改成员数据

**const 与 #define 比较：**
- `const` 有类型检查；`#define` 是纯文本替换
- `const` 作用域遵循 C++ 规则；`#define` 从定义处到文件尾

#### 1.2.2 内联函数 (inline)

```cpp
inline int max(int a, int b) { return a > b ? a : b; }
```
- **特点：** 编译器将函数体展开到调用处，减少函数调用开销
- **适用：** 功能简单、代码少、被频繁调用的函数
- **注意：** inline 是对编译器的建议，非强制；函数体过大或含循环时编译器通常忽略
- **区别：** 内联函数在编译时展开；宏在预处理时展开（无类型检查）

#### 1.2.3 默认参数

```cpp
void func(int a, int b=5, char c='*');  // 正确：默认参数自右向左
// void func(int a=1, int b, char c='*');  // 错误！不能隔断
func(10);     // 正确：a=10, b=5, c='*'
func(10, 8);  // 正确：a=10, b=8, c='*'
```

**规则：** 默认参数必须从右往左连续设置，不能有间隔。

#### 1.2.4 函数重载

```cpp
int add(int a, int b);      // (1)
double add(double a, double b); // (2) 类型不同 → 合法重载
int add(int a, int b, int c);   // (3) 个数不同 → 合法重载
// int add(int x, int y);       // (4) 仅返回值不同 → 不合法！
```

**规则：**
- 函数名相同，参数列表（类型/个数/顺序）不同
- 仅返回值类型不同**不能**构成重载
- `void f(int)` 和 `void f(const int)` 不构成重载（顶层 const 被忽略）

#### 1.2.5 new 和 delete

```cpp
int *p = new int;          // 分配单个 int
int *p = new int(10);      // 分配并初始化为 10
int *p = new int[100];     // 分配数组
delete p;                  // 释放单个对象
delete[] p;                // 释放数组（必须配对！）
```

| `new` | `malloc` |
|-------|----------|
| 运算符 | 函数 |
| 自动调用构造函数 | 不调用构造函数 |
| 返回正确类型指针 | 返回 `void*`，需强制转换 |
| 失败抛异常 | 失败返回 NULL |

#### 1.2.6 引用 (Reference)

```cpp
int a = 10;
int &b = a;   // b 是 a 的引用（别名）
b = 20;       // 此时 a = 20
```

**引用 vs 指针 vs 值参数：**

| 传递方式 | 语法 | 是否修改实参 | 开销 |
|----------|------|-------------|------|
| 值传递 | `void f(int x)` | 否 | 副本拷贝 |
| 引用传递 | `void f(int &x)` | **是** | 无拷贝 |
| 指针传递 | `void f(int *x)` | **是** | 无拷贝 |

**引用声明规则：**
- 引用必须在声明时初始化，不能先声明后赋值
- 引用一旦绑定不能更改指向
- 引用作形参时，实参必须是变量名或对象名

#### 1.2.7 作用域运算符 `::`

```cpp
int x = 100;            // 全局变量
void func() {
    int x = 10;         // 局部变量
    cout << x;          // 输出 10（局部）
    cout << ::x;        // 输出 100（全局）
}
```

### 1.3 教材习题精选

## 第 2 章：类和对象

### 2.1 类的基本定义

```cpp
class Student {           // class 默认访问权限：private
public:                   // 公有：任何地方可访问
    void display();       // 成员函数
    int getNum() const;   // 常成员函数
private:                  // 私有：仅本类成员函数可访问
    int num;
protected:                // 保护：本类和派生类可访问
    float score;
};
// 类外定义成员函数
void Student::display() { cout << num << " " << score << endl; }
```

**结构体和类的区别：** `struct` 默认访问权限是 `public`，`class` 默认是 `private`。

### 2.2 构造函数与析构函数

| 特点 | 构造函数 | 析构函数 |
|------|---------|---------|
| 函数名 | 与类名相同 | `~` + 类名 |
| 返回值 | 无（不可指定） | 无 |
| 参数 | 可以有 | **无** |
| 重载 | **可以重载** | 不可重载 |
| 默认生成 | 未定义时自动生成 | 未定义时自动生成 |
| 被继承 | 不能被继承 | 不能被继承 |
| 调用时机 | 创建对象时自动调用 | 撤销对象时自动调用 |

**构造函数的类型：**

```cpp
class A {
public:
    A();                  // 默认构造函数
    A(int x);             // 转换构造函数（单参数）
    A(int x, int y);      // 一般构造函数
    A(const A &a);        // 拷贝构造函数
};
```

**拷贝构造函数调用时机：**
1. 用一个对象初始化同类的另一个新对象：`A b(a);` 或 `A b = a;`
2. 函数的形参是类的对象，值传递时：`void f(A obj)`
3. 函数的返回值是类的对象：`A f() { return obj; }`

> **注意：** 对象引用/指针做参数时**不调用**拷贝构造函数。

```cpp
// 拷贝构造函数的正确写法
A::A(const A &a) : x(a.x) { }  // 必须用引用，否则无限递归
```

### 2.3 初始化列表

```cpp
class A {
    const int cdata;       // 常数据成员（必须在初始化列表初始化）
    int &ref;              // 引用成员（必须在初始化列表初始化）
    int x;
public:
    A(int c, int r, int v) : cdata(c), ref(r), x(v) { }
};
```

**必须在初始化列表中初始化的成员：** 常数据成员（const）、引用成员（&）、成员对象（无默认构造时）。

**初始化顺序：** 按成员在类中声明的顺序，**不是**按初始化列表中的顺序。

### 2.4 静态成员 (static)

```cpp
class A {
    static int count;      // 声明（不占用对象空间）
    static int getCount(); // 静态成员函数
};
int A::count = 0;          // 类外初始化（必须！）
```

**关键点：**
- 静态数据成员属于类，所有对象共享同一份
- 必须在**类外初始化**
- 静态成员函数**无 this 指针**
- 静态成员函数只能直接访问静态数据成员（不能访问非静态成员）
- 可通过类名调用：`A::getCount()` 或 `A::count`

### 2.5 this 指针

```cpp
class A {
    int x;
public:
    A(int x) { this->x = x; }  // 区分形参和成员
    A& setX(int x) {
        this->x = x;
        return *this;           // 返回对象引用，支持链式调用
    }
};
```
- `this` 是一个隐含的常量指针，指向当前调用成员函数的对象
- 不能修改 `this` 的指向

### 2.6 友元 (friend)

```cpp
class B;   // 提前引用声明

class A {
    friend class B;              // 友元类：B 的所有成员可访问 A 的私有成员
    friend void func(A &a);      // 友元函数（普通函数）
    friend void B::show(A &a);   // 友元函数（其他类的成员函数）
private:
    int data;
};
```

**友元特点：**
- 不是类的成员函数
- 可访问类的所有成员（包括私有）
- 破坏了封装性和隐藏性
- **不具有交换性：** A 是 B 的友元 ≠ B 是 A 的友元
- **不具有传递性：** A 是 B 的友元，B 是 C 的友元 ≠ A 是 C 的友元
- **不可继承**

### 2.7 常类型 (const)

```cpp
const A obj(10);       // 常对象：不能被更新
obj.getX();            // 正确：调用常成员函数
// obj.setX(5);        // 错误！常对象不能调用非 const 函数

class A {
    int x;
public:
    void func() const {   // 常成员函数：不能修改任何数据成员
        // x = 10;        // 错误！
        cout << x;        // 可以读
    }
};
```

**规则：** 常对象只能调用常成员函数；常成员函数不能修改任何数据成员。

### 2.8 对象成员（类的组合）

```cpp
class A { /* ... */ };
class B {
    A a;              // 对象成员（内嵌对象）
public:
    B() : a() { }     // 通过初始化列表初始化对象成员
};
```

**构造/析构执行顺序：**

| 构造顺序 | 析构顺序 |
|---------|---------|
| ① 基类 | ① 派生类自身 |
| ② 成员对象（按声明顺序） | ② 成员对象（反向顺序） |
| ③ 派生类自身 | ③ 基类 |

> **记忆：** 构造从基类到派生类（先长辈后晚辈），析构相反（像栈一样后进先出）

### 2.9 教材习题精选

**程序分析题（常考）：**

1. 构造与析构顺序：
```cpp
class A {
public: A() { cout<<"A"; }
        ~A() { cout<<"~A"; }
};
class B {
    A *p;
public:
    B() { cout<<"B"; p=new A(); }
    ~B() { cout<<"~B"; delete p; }
};
int main() { B obj; return 0; }
// 输出：BA~B~A
// 解析：B 构造函数先执行 cout<<"B"，再 new A() 输出 "A"；析构时先 ~B 再 delete p 调用 ~A
```

2. 拷贝构造：
```cpp
class myClass {
public:
    myClass(int i=0):n(i) { cout<<'A'; }
    myClass(myClass &c):n(c.getValue()) { cout<<'C'; }
    int getValue() const { return n;}
    ~myClass() { cout<<'D'; }
private: int n;
};
void show(myClass c) { cout<<c.getValue(); }
int main() {
    myClass c1;
    show(c1);
    myClass c2(2);
    show(c2);
    return 0;
}
// 输出：AC0DAC2DDD
// 解析：c1 默认构造 A → show(c1) 拷贝构造 C 输出 0 → show 结束析构 D → c2(2) 构造 A → show(c2) 拷贝构造 C 输出 2 → show 结束析构 D → main 结束析构 c2 D → 析构 c1 D
```

3. static + const 重载：
```cpp
class Fun {
public:
    static int i;
    Fun() {i++;}
    int value() {return i-1;}
    int value() const {return i+1;}
};
int Fun::i=2;
int main() {
    Fun fun1;
    const Fun fun2;
    cout<<fun1.value()<<fun2.value()<<Fun::i<<endl;
    return 0;
}
// 输出：354
// 解析：fun1 非 const 调 value() → i=3 → 输出 3；fun2 const 调 const 版 → i=4 → 输出 5；Fun::i=4 → 输出 4
```

## 第 3 章：继承与派生

### 3.1 继承方式与访问控制

| 基类成员 \ 继承方式 | `public` 继承 | `protected` 继承 | `private` 继承 |
|-------------------|--------------|-----------------|---------------|
| `public` | `public` | `protected` | `private` |
| `protected` | `protected` | `protected` | `private` |
| `private` | 不可访问 | 不可访问 | 不可访问 |

**规则：** 基类的 `private` 成员无论何种继承方式，在派生类中**都不可直接访问**。

```cpp
class Base {
public:    int a;
protected: int b;
private:   int c;
};
class Pub : public Base {
    // a → public,   b → protected,  c → 不可访问
};
class Pro : protected Base {
    // a → protected, b → protected, c → 不可访问
};
class Pri : private Base {
    // a → private,   b → private,   c → 不可访问
};
```

**`protected` 和 `private` 的异同：**
- 相同：都不能通过类对象在外部访问
- 不同：`protected` 成员可以被派生类访问；`private` 成员不能被派生类访问

### 3.2 派生类的构造与析构

```cpp
class Base {
public:
    Base(int i) { cout<<"Base("<<i<<")"; }
    ~Base() { cout<<"~Base()"; }
};
class Derived : public Base {
public:
    // 派生类构造函数必须通过初始化列表调用基类构造函数
    Derived(int i, int j) : Base(i), data(j) { cout<<"Derived("<<j<<")"; }
    ~Derived() { cout<<"~Derived()"; }
private:
    int data;
};
// 构造顺序：Base → Derived
// 析构顺序：~Derived → ~Base
```

**构造规则：**
1. 先调用基类构造函数（按继承顺序）
2. 再调用成员对象的构造函数（按声明顺序）
3. 最后执行派生类构造函数体
4. 析构顺序与构造完全相反

### 3.3 同名成员的访问

在派生类中访问基类的同名成员时，使用类域限定符 `::`：

```cpp
class Base { public: void f() { cout<<"Base"; } };
class Derived : public Base {
public:
    void f() { cout<<"Derived"; }      // 隐藏了基类的 f()
    void g() { Base::f(); }            // 调用基类的 f()
};
```

### 3.4 多继承

```cpp
class A { public: void f(); };
class B { public: void f(); void g(); };
class C : public A, public B {
public:
    void g() { }      // 重定义了 g()，隐藏了 B::g()
};
C c;
// c.f();          // 二义性错误！A 和 B 都有 f()
c.A::f();          // 正确：用类域限定
c.B::g();          // 正确：调用 B::g()
c.g();             // 正确：调用 C::g()
```

### 3.5 虚基类 (virtual)

**目的：** 消除多继承中的二义性（菱形继承）

```cpp
// 非虚继承 — D 中有两份 A 的成员
class A { public: int n; };
class B : virtual public A { };   // 虚继承
class C : virtual public A { };   // 虚继承
class D : public B, public C { };

D d;
d.n = 10;  // 正确！虚基类确保只有一份 A
```

**虚基类构造函数规则：** 在最后的派生类中，虚基类的构造函数由**最派生类**直接调用，且只调用一次。

### 3.6 赋值兼容规则

在类的继承层次中，派生类对象可以赋值给基类对象：

```cpp
class Base { };
class Derived : public Base { };

Derived d;
Base b;
Base *pb = &d;          // 派生类对象地址 → 基类指针
Base &rb = d;           // 派生类对象 → 基类引用
b = d;                  // 派生类对象 → 基类对象（对象切片）

// 反方向不成立：
// Derived *pd = &b;    // 错误！基类不能赋给派生类
```

### 3.7 教材习题精选

## 第 4 章：多态性

### 4.1 多态概述

| 类型 | 联编方式 | 实现机制 | 发生时期 |
|------|---------|---------|---------|
| **编译时多态**（静态多态） | 静态联编 | 函数重载、运算符重载 | 编译期 |
| **运行时多态**（动态多态） | 动态联编 | **虚函数** | 运行期 |

### 4.2 虚函数 (virtual)

```cpp
class Base {
public:
    virtual void func() { cout<<"Base"; }  // 虚函数
    void show() { cout<<"Base show"; }     // 非虚函数
};
class Derived : public Base {
public:
    void func() { cout<<"Derived"; }      // 重写（override）
    void show() { cout<<"Derived show"; }
};

Base *p = new Derived();
p->func();   // 输出：Derived（虚函数 → 动态联编）
p->show();   // 输出：Base show（非虚函数 → 静态联编）
```

**实现运行时多态的三个必要条件：**
1. 公有派生类层次关系
2. 基类中声明虚函数
3. 通过基类指针或引用调用虚函数

**虚函数特性：**
- `virtual` 只需在基类声明，派生类自动继承虚特性
- 派生类中重写虚函数必须与基类**签名一致**（函数名、参数、返回类型）
- 基类析构函数应声明为 `virtual`（防止内存泄漏）
- 构造函数不能是虚函数

**虚析构函数：**
```cpp
class A {
public:
    virtual ~A() { cout<<"A::~A()"; }
};
class B : public A {
    char *buf;
public:
    B(int i) { buf = new char[i]; }
    virtual ~B() { delete[] buf; cout<<"B::~B()"; }
};
A *p = new B(10);
delete p;  // 先调 B::~B() → 再调 A::~A()（若基类析构非 virtual 则只调 A）
```

### 4.3 纯虚函数与抽象类

```cpp
class Shape {
public:
    virtual double area() = 0;  // 纯虚函数（= 0）
    virtual double perimeter() = 0;
};

// Shape s;           // 错误！抽象类不能创建对象
Shape *p;              // 正确，可以声明指针
Shape &r;              // 正确，可以声明引用

class Circle : public Shape {
public:
    double area() { return 3.14 * r * r; }
    double perimeter() { return 2 * 3.14 * r; }
};
Circle c;              // 正确！派生类实现了所有纯虚函数才能实例化
```

**抽象类特性：**
- 含有纯虚函数的类称为抽象类
- 不能定义抽象类的对象
- 可定义抽象类的指针和引用（实现多态）
- 派生类必须实现所有纯虚函数才能实例化

### 4.4 对象切片 (Object Slicing)

```cpp
class A { public: virtual void pr(){cout<<"111";} };
class B: public A { public: void pr(){cout<<"222";} };
void p1(A &a) { a.pr(); }   // 引用传递 → 动态联编 → 调 B::pr()
void p2(A a) { a.pr(); }     // 值传递 → 对象切片 → 调 A::pr()
int main() {
    B b; p1(b); p2(b); return 0;
}
// 输出：222111
```

> **结论：** 多态必须用指针或引用，**不能用值传递**，否则派生类部分被"切片"丢失。

### 4.5 运算符重载

#### 4.5.1 两种重载形式

| 特点 | 成员函数重载 | 友元函数重载 |
|------|-------------|-------------|
| 参数个数 | 操作数个数 - 1（隐含 this） | 操作数个数 |
| 左操作数 | 必须是对象（*this） | 可以是其他类型 |
| 典型语法 | `a.operator+(b)` | `operator+(a, b)` |

**只能重载为成员函数的运算符：** `=` `[]` `()` `->`

**不能重载的运算符：** `.` `::` `.*` `?:` `sizeof`

#### 4.5.2 常见运算符重载

**赋值运算符 `=`：**
```cpp
String& String::operator=(const String& str) {
    if(this != &str) {                    // 防止自赋值
        delete[] _string;                  // 释放原有内存
        _size = str._size;
        _string = new char[_size + 1];
        strcpy(_string, str._string);
    }
    return *this;                          // 返回引用，支持链式赋值
}
```

**流插入/提取运算符 `<<` / `>>`：**
```cpp
// << 重载（必须用友元）
ostream& operator<<(ostream& out, const Complex& c) {
    out << c.real;
    if(c.imag > 0) out << "+";
    if(c.imag != 0) out << c.imag << "i";
    return out;
}

// >> 重载
istream& operator>>(istream& in, Complex& c) {
    cout << "Input real and imag:";
    in >> c.real >> c.imag;
    return in;
}
```

**复数类 Complex 完整重载：**
```cpp
class Complex {
    double real, imag;
public:
    Complex(double r=0, double i=0): real(r), imag(i) {}
    Complex operator+(const Complex &c) const {  // 成员重载
        return Complex(real+c.real, imag+c.imag);
    }
    friend ostream& operator<<(ostream& os, const Complex& c);
    friend Complex operator-(const Complex& a, const Complex& b); // 友元重载
};
ostream& operator<<(ostream& os, const Complex& c) {
    os << "(" << c.real << "," << c.imag << ")";
    return os;
}
Complex operator-(const Complex& a, const Complex& b) {
    return Complex(a.real - b.real, a.imag - b.imag);
}
```

**前置 ++ 与后置 ++ 的重载：**
```cpp
class Counter {
    int val;
public:
    Counter& operator++() {    // 前置 ++
        ++val;
        return *this;
    }
    Counter operator++(int) {  // 后置 ++（int 参数是占位符，无实际作用）
        Counter temp = *this;
        val++;
        return temp;           // 返回自增前的值
    }
};
```

## 第 5 章：模板

### 5.1 函数模板

```cpp
// 求两个数中的最大值
template <typename T>
T max(T a, T b) { return (a > b) ? a : b; }

// 使用
cout << max(3, 5);          // 自动推导 T=int
cout << max(3.0, 5.5);     // 自动推导 T=double

// max(3, 5.5);             // 错误！T 不能同时推导为 int 和 double
```

**函数模板与重载的普通函数并存时调用顺序：**
```cpp
template <typename T> T max(T a, T b);  // 函数模板
int max(int a, int b);                  // 普通函数重载

max(3, 5);       // 优先调用普通函数（完全匹配）
max(3.0, 5.5);   // 调用函数模板（推导为 double）
max<int>(3, 5);  // 调用函数模板（显式指定）
```

```cpp
template <typename T>
class Stack {
    T data[100];
    int top;
public:
    Stack() : top(-1) {}
    void push(T x) { data[++top] = x; }
    T pop() { return data[top--]; }
};

Stack<string> s2;
```

**类模板的派生：**
- 从类模板派生出类模板：`template <class T> class Derived : public Base<T> {}`
- 从类模板派生出普通类：`class Specific : public Base<int> {}`
- 从普通类派生出类模板：`template <class T> class Derived : public NormalClass {}`

## B3：简答题（附答案）

**1. 简述面向过程分析和面向对象分析的区别。**
> 面向过程：分析出解决问题所需要的步骤，用函数实现，依次调用。面向对象：将问题分解成各个对象，建立对象以描述事物在解决问题中的行为。面向过程以功能为中心（程序=算法+数据结构）；面向对象以数据为中心（程序=对象/类）。

**2. 类的对象能直接调用其私有成员吗？为什么？**
> 不能。私有成员只能被本类成员函数及友元访问，外部函数无法访问，以实现信息隐藏。

**3. 什么是内联函数？它具有哪些特点？**
> 用 inline 关键字定义的函数。特点：编译器将函数体直接嵌入调用处，减少函数调用开销；适用于功能简单的函数；inline 是对编译器的建议，可被忽略。

**4. 什么是抽象类？抽象类有何作用？**
> 含有纯虚函数的类称为抽象类。作用：为一类组提供统一的操作接口（纯虚函数）；自身不能实例化，只能作为基类派生新类；将相关派生类组织在一个继承层次中。

**5. 什么是面向对象中的消息？一条消息由哪几部分组成？**
> 消息是对象之间发出的行为请求。由三部分组成：接受消息的对象、消息名称、若干消息参数。

**6. 在 C++ 中引入纯虚函数的作用是什么？**
> 使基类本身不能生成对象（抽象类），强制派生类重写该函数。为相关类提供统一接口，实现多态性。

**7. 类的三个主要特征是什么？用实例说明。**
> 封装（如 class 将数据和函数封装，通过 private/public 控制访问）、继承（如 Student 类从 Person 类继承姓名和年龄）、多态（如 Shape 类的 area() 函数在 Circle 和 Rectangle 中有不同实现）。

**8. 继承方式的种类及其各自的特点是什么？构造和析构函数的调用规则？**
> 公有继承：基类 public→public, protected→protected；保护继承：基类 public/protected→protected；私有继承：基类 public/protected→private。基类 private 在任何继承方式下都不可直接访问。
> 构造顺序：基类→成员对象→派生类。析构相反。

**9. 为什么要引入虚基类？为什么要引入虚函数？**
> 虚基类：解决多继承中"菱形继承"产生的二义性。
> 虚函数：实现运行时多态性，即"同一接口，多种方法"。

定义并实现一个矩形类，包含左上角坐标、长、宽，实现求周长、面积、输出顶点坐标等功能。

```cpp
#include <iostream>

class Rectangle {
public:
    // 构造函数
    Rectangle(int x=0, int y=0, int l=1, int w=1)
        : left(x), top(y), length(l), width(w) {}

    void setLength(int l) { length = l; }
    void setWidth(int w) { width = w; }

    int getWidth() { return width; }
    int getLength() { return length; }
    
    // 输出四个顶点坐标
    void printRectangle() {

        cout << "顶点3: (" << left << "," << top+width << ")" << endl;
        cout << "顶点4: (" << left+length << "," << top+width << ")" << endl;

private:
```

**6. 函数模板：求三个数的最大值**

```cpp
#include <iostream>
using namespace std;

template <class AnyType>
class Complex {
    AnyType a, b, c;
public:
    Complex(AnyType x, AnyType y, AnyType z) : a(x), b(y), c(z) {}
    AnyType max() {
        AnyType t = a;
        if(b > t) t = b;
        if(c > t) t = c;
        return t;
    }
};

int main() {
```

**7. 栈类模板**

```cpp
#include <iostream>
using namespace std;
const int MaxSize = 100;

template <class T>
class Stack {
    T elem[MaxSize];
    int top;
public:
    Stack() : top(-1) {}
    void push(const T &a) {
        if(top == MaxSize-1) return;
        elem[++top] = a;
    }
    void pop() { if(top >= 0) top--; }
    T getTop() { return (top >= 0) ? elem[top] : 0; }
    bool empty() { return top == -1; }
    int size() { return top + 1; }
};

int main() {
    Stack<int> s;
    s.push(10); s.push(20);
    cout << s.getTop() << endl;  // 20
    s.pop();
    cout << s.getTop() << endl;  // 10
    return 0;
}
```

## C3：易混淆概念速查

| 混淆对 | 辨析 |
|--------|------|
| `const int *p` vs `int *const p` | 前者指向常量的指针（值不可改）；后者常量指针（指向不可改） |
| `int *p[5]` vs `int (*p)[5]` | 前者指针数组（5 个指针）；后者数组指针（指向 5 个 int 的数组） |
| `strlen` vs `sizeof` | `strlen("abc")`=3（不含 \\0）；`sizeof("abc")`=4（含 \\0） |
| `new` vs `malloc` | new 调构造 + 返回正确类型；malloc 不调构造 + 返回 void* |
| 重载 vs 隐藏 vs 重写 | 重载（同作用域，参数不同）；隐藏（不同作用域，同名）；重写（virtual，签名相同） |
| 成员重载 vs 友元重载 | 成员参数少一个（this）；友元参数与操作数个数相同 |
| 公有继承 vs 私有继承 | 公有继承保持访问权限；私有继承使基类公有/保护成员变为私有 |
| 抽象类 vs 虚基类 | 抽象类含纯虚函数不能实例化；虚基类解决多继承二义性 |
