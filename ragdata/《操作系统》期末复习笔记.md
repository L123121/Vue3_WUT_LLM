## 一、操作系统概述

### 1.1 操作系统的特征【必考】

1. **并发**：多个事件在同一时间间隔内发生（宏观并行、微观串行）。
2. **共享**：资源共享方式分为互斥共享（打印机）和同时共享（磁盘）。
3. **虚拟**：一个物理实体映射为若干逻辑对应物（虚拟处理器、虚拟内存）。
4. **异步**：进程以不可预知的速度向前推进。

### 1.2 处理器运行状态

- **用户态（目态）**：只能执行非特权指令。
- **核心态（管态）**：可执行特权指令（I/O、置时钟、开关中断）。
- 用户态→核心态唯一途径：**中断/异常**；核心态→用户态：执行恢复现场指令（如修改程序状态字）。

### 1.3 中断分类

| 类型 | 示例 | 是否与当前进程相关 |
|------|------|:---:|
| 外部中断 | 时钟中断、I/O 完成中断 | 否 |
| 内部异常 | 缺页故障、除零、越权指令 | 是 |

## 二、进程与线程【必考】

### 2.1 进程的组成与状态转换

进程实体 = 程序段 + 数据段 + **PCB**（进程控制块，唯一标志）。

三基本状态转换图（必画）：

```
        时间片到/调度
 就绪 ───────────────▶ 运行
  ▲                    │  │ 等待某事件（I/O请求、P操作）
  │ 时间片到            │  ▼
  └── 时间片轮转 ◀──── 等待(阻塞)
       事件发生（V操作、I/O完成）
```

要点：

- 运行→就绪：时间片用完或被更高优先级抢占。
- 运行→阻塞：**主动**行为（等待 I/O）；阻塞→就绪：**被动**行为（等待的事件发生）。
- 不存在"阻塞→运行"的直接转换。

### 2.2 PCB 的作用

记录进程标识信息（PID）、处理机状态（程序计数器、寄存器现场）、进程调度信息与控制信息。进程切换时保存与恢复现场都依赖 PCB。

### 2.3 进程 vs 线程【必考】

| 维度 | 进程 | 线程 |
|------|------|------|
| 定位 | 资源分配的基本单位 | CPU 调度的基本单位 |
| 地址空间 | 独立 | 同进程内共享（代码、数据、堆），独享栈与寄存器 |
| 切换开销 | 大（换页表、换上下文） | 小（同进程内不换地址空间） |
| 通信 | 需要 IPC（管道、消息队列、共享内存、信号量、socket） | 直接读写全局变量（需同步） |

### 2.4 调度算法对比【必考】

| 算法 | 规则 | 优点 | 缺点 | 可否饥饿 |
|------|------|------|------|:---:|
| FCFS 先来先服务 | 按到达顺序 | 公平简单 | 对短作业不利（护航效应） | 会 |
| SJF 短作业优先 | 运行时间最短者优先 | 平均等待时间最短 | 对长作业不利，需预知时长 | 会 |
| HRRN 高响应比 | (等待+要求服务)/要求服务 | 折中 FCFS 与 SJF | 每次需计算响应比 | 不会 |
| RR 时间片轮转 | 按 FCFS 排队，轮流执行一个时间片 | 响应快，适合交互 | 时间片选择影响大：太小→切换频繁；太大→退化为 FCFS | 不会 |
| 多级反馈队列 | 多队列+优先级+时间片递增 | 兼顾响应与吞吐，通用性好 | 实现复杂 | 会（低优先级） |

计算题型：给出到达时间与服务时间的进程表，按指定算法求**周转时间 = 完成时间 − 到达时间**、**带权周转时间 = 周转时间 / 服务时间**、平均等待时间。注意 SJF 默认非抢占，SRTF 才是抢占式最短剩余时间优先。

## 三、进程同步与互斥【必考】

### 3.1 基本概念

- **临界资源**：一次仅允许一个进程使用的资源。
- **临界区**：进程中访问临界资源的那段代码。进入区（P/加锁）→ 临界区 → 退出区（V/解锁）→ 其余区。
- 同步（直接制约）：协调执行次序；互斥（间接制约）：排他使用临界资源。

### 3.2 信号量机制【必考】

整型/记录型信号量，P(wait) 与 V(signal) 的语义：

```
P(S): S.value--; if (S.value < 0) block(self);   // 负值绝对值 = 等待进程数
V(S): S.value++; if (S.value <= 0) wakeup(head);
```

经典模型：

**① 生产者-消费者（必须会默写）**

```
semaphore mutex = 1;      // 互斥访问缓冲区
semaphore empty = n;      // 空闲缓冲区数
semaphore full  = 0;      // 产品数

生产者:                     消费者:
while(true){                while(true){
  生产一个产品;               P(full);
  P(empty);                   P(mutex);
  P(mutex);                   取出产品;
  放入产品;                   V(mutex);
  V(mutex);                   V(empty);
  V(full);                    消费;
}                           }
```

⚠️ 易错点：**两个 P 操作顺序不能颠倒**（先互斥后同步会造成死锁）；两个 V 可以颠倒。

**② 读者-写者**：读读共享、读写互斥、写写互斥。用计数器 + 保护计数器的 mutex 实现"第一个读者上锁、最后一个读者解锁"。

**③ 哲学家进餐**：解决死锁的三种思路——最多允许 4 人同时拿筷子；奇数号先拿左筷偶数号先拿右筷；一次性申请两只筷子（AND 信号量）。

**④ 吸烟者问题 / 理发师问题**：生产者-消费者的变体，注意"一个位置放一个产品"时 full 初值为 0、empty 为 1。

### 3.3 管程

将共享数据及其操作封装为对象，同一时刻只允许一个进程在管程内执行，互斥由编译器保证；条件变量 condition 配合 wait/signal 实现同步。Java 的 synchronized + wait/notify 是管程思想的落地。

### 3.4 其他知识点

- 原子操作实现互斥：test-and-set（TS 指令）、swap 指令、单标志法/双标志先检查法（违反空闲让进/忙则等待）、Peterson 算法（软件方案完整解）。
- 用户级线程 vs 内核级线程：ULT 切换不需内核介入但一个阻塞全阻塞；KLT 可并行但切换要陷入内核。

## 四、死锁【必考】

### 4.1 定义与四必要条件

死锁：多个进程互相等待对方持有的资源，均无法推进。

1. **互斥**
2. **占有且等待（请求并保持）**
3. **不可剥夺（不可抢占）**
4. **循环等待**（充分条件之一，形成环路）

### 4.2 处理策略对比

| 策略 | 思路 | 时机 |
|------|------|------|
| 预防 | 静态破坏四个条件之一（一次性申请全部资源=破占有等待；资源有序分配=破循环等待） | 事前 |
| 避免 | 动态判断分配后是否进入不安全状态（银行家算法） | 分配时 |
| 检测+解除 | 资源分配图检测环，解除靠剥夺/撤销/回退 | 事后 |
| 鸵鸟策略 | 不管，多数通用 OS 采用 | — |

### 4.3 银行家算法【必考·大题】

数据结构：Available(m)、Max(n×m)、Allocation(n×m)、Need = Max − Allocation。

判定步骤：

1. 求 Work = Available，Finish 全 false。
2. 找 Needᵢ ≤ Work 且 Finish[i]=false 的进程 i，假设其完成后释放：Work += Allocationᵢ，Finish[i]=true。
3. 重复直到找不到；若所有 Finish=true → **安全状态**，序列即安全序列；否则不安全（不安全 ≠ 必死锁，但可能死锁）。

小题常考：给矩阵问"某请求能否满足"——先试探分配，再跑安全性检测，安全则同意否则让进程等待。

### 4.4 死锁定理

对资源分配图进行化简（消去既非孤立又非孤立的边），能完全化简则无死锁；不能化简的进程集合即为死锁进程。

## 五、内存管理【必考】

### 5.1 连续分配

| 方式 | 思想 | 缺点 |
|------|------|------|
| 单一连续分配 | 内存分系统区与用户区 | 无外部碎片，利用率低 |
| 固定分区 | 预先划固定大小分区 | 有内部碎片 |
| 动态分区 | 按需划分 | 无内部碎片，产生**外部碎片** |

动态分区分配算法：**首次适应**（从头找第一个够用，综合性能最好）、**最佳适应**（最小够用块，产生大量小碎片）、**最坏适应**（最大块，大进程易饿死）、**邻近适应**（从上次位置继续找）。

外部碎片解决方案：**紧凑/拼接**（需要重定位支持）。

### 5.2 分页存储【必考】

- 逻辑空间等分为**页**，物理空间等分为**页框/块**，页大小通常 4KB（2¹²）。
- 地址结构：页号 P + 页内偏移 W。物理地址 = f(P) × 页大小 + W。
- **页表**记录页→页框映射；引入**页表寄存器 PTBR** 存放页表起始地址与长度。
- 两级/多级页表：解决页表本身太大占用连续内存的问题；代价是访存次数增加（两级页表一次取数共 3 次访存，无快表时）。
- 访存有效时间 EAT = 快表命中率相关公式：EAT = h×(t_tlb + t_mem) + (1−h)×(t_tlb + 2×t_mem)（一级页表情形）。

计算模板（每年必考类型）：
已知页大小 4KB、逻辑地址 A：P = A / 4096（二进制取高 20 位），W = A mod 4096（低 12 位）；查页表得页框号 F，物理地址 = F << 12 | W。

### 5.3 分段与段页式

- **分段**：按逻辑意义划分（代码段、数据段、栈段），段长可变，地址 = (段号 s, 段内偏移 w)，段表项含段长 → 需做**越界检查**；便于共享保护，产生外部碎片。
- **段页式**：先分段再分页，每段一张页表；取数需 3 次访存（段表、页表、数据）。

| 对比项 | 分页 | 分段 |
|------|------|------|
| 划分依据 | 物理（固定大小） | 逻辑（可变大小） |
| 碎片 | 内部碎片（最后一页） | 外部碎片 |
| 共享保护 | 困难（不按逻辑边界） | 容易 |
| 对用户 | 透明 | 可见 |

## 六、虚拟内存与页面置换【必考·大题】

### 6.1 虚拟内存基础

- 基于**局部性原理**（时间局部性 + 空间局部性）。
- 特征：多次性、对换性、虚拟性（容量 = min(内外存之和, 机器位数决定的空间)）。
- 请求分页 = 纯分页 + 请求调页 + 页面置换；页表新增字段：状态位、访问位、修改位（脏位）、外存地址。

### 6.2 缺页中断处理流程

1. 硬件捕获缺页异常，陷入内核。
2. 检查是否越界访问（非法 → 终止进程）。
3. 外存找到目标页：有空闲页框 → 直接装入；无空闲 → 执行置换算法选牺牲页。
4. 牺牲页若被修改过（脏页）须先写回外存。
5. 更新页表置有效位，重新执行引起缺页的指令。

缺页中断属于**内中断**，且一条指令执行期间可能多次缺页。

### 6.3 页面置换算法【必考】

| 算法 | 规则 | 特点 |
|------|------|------|
| OPT 最佳置换 | 淘汰未来最长时间不再访问的页 | 无法实现，作性能上限基准 |
| FIFO 先进先出 | 淘汰最早进入的页 | 可能出现 Belady 异常（页框增多缺页反而增多） |
| LRU 最近最久未使用 | 淘汰最长时间未被访问的页 | 性能接近 OPT，硬件开销大（计数器/栈实现） |
| CLOCK 简称 NRU | 循环扫描访问位，1 清 0 跳过、0 淘汰 | LRU 的低开销近似，第二机会算法 |

**计算题模板**：给定访问串（如 7,0,1,2,0,3,0,4…）与页框数 3，逐列表格模拟，统计缺页次数 → 缺页率 = 缺页次数 / 访问总次数。注意：**初始装入也算缺页**（题目另有说明除外）。

### 6.4 抖动（颠簸）

刚换出的页马上又要访问导致系统忙于换页。原因：分配页框太少或多道度太高。解决：工作集模型（按时间窗口 t 内访问页集合分配页框）、降低多道程序度、缺页率反馈调节。

## 七、文件系统

### 7.1 文件逻辑结构与目录

- 逻辑结构：顺序文件、索引文件、索引顺序文件。
- 目录实现：FCB（文件控制块）集合 → 索引节点 inode（UNIX：把文件名与元数据分离，目录项只存文件名 + inode 号，提升检索效率）。
- **硬链接**与符号链接：硬链接共享 inode，计数归零才删除；符号链接是独立文件存路径，原文件删除后成悬空链接。

### 7.2 文件物理结构

| 结构 | 思想 | 特点 |
|------|------|------|
| 连续分配 | 连续盘块 | 支持随机存取，难扩展，外部碎片 |
| 链接分配 | 隐式/显式链 | 无外部碎片，随机存取慢（显式 FAT 在内存中查表可改善） |
| 索引分配 | 索引块集中映射 | 支持随机存取；大文件用**混合索引**（直接块 + 一级/二级间接块） |

混合索引计算题：设块 4KB、块指针 4B → 一个索引块可指向 1024 块；10 个直接块 + 1 个一级 + 1 个二级间接块的文件最大长度 = (10 + 1024 + 1024²) × 4KB ≈ 4GB+。

### 7.3 磁盘管理与调度【常考计算】

- 磁盘地址 = (柱面/磁道, 磁头/盘面, 扇区)；读取时间 = 寻道时间 + 旋转延迟 + 传输时间。
- **SSTF** 最短寻道优先：贪心最近柱面，可能饥饿。
- **SCAN 电梯算法**：沿一个方向扫到端点再折返；**C-SCAN**：单向扫描快速返回，等待时间更均匀。
- 计算题：给当前磁道与请求队列，求各算法移动道数总和。

## 八、I/O 与设备管理

### 8.1 I/O 控制方式演进

```
程序直接控制（CPU 轮询忙等）
  → 中断驱动（CPU 与 I/O 并行，逐字节中断）
  → DMA（以块为单位，仅传输开始/结束打扰 CPU）
  → 通道（专用处理器，一组块、一组设备）
```

CPU 介入频率依次降低，并行度依次提高。

### 8.2 缓冲与假脱机

- 单缓冲/双缓冲/循环缓冲/缓冲池：双缓冲下一块数据的处理可与下一块的输入并行。
- **SPOOLing 假脱机**：用磁盘上的输入/输出井把独占设备改造为共享设备（打印机是典型），外围控制机模拟脱机 I/O。

### 8.3 设备分配与驱动

- DCT（设备控制表）、COCT、CHCT 层层查找；设备独立性软件屏蔽差异，通过逻辑设备名映射物理设备。
- 中断处理过程：关中断 → 保存现场 → 中断向量定位处理程序 → 处理 → 恢复现场返回。

## 常见问题

### 时间片大小如何权衡？

时间片过大退化为 FCFS、交互响应差；过小则上下文切换开销占比过高。经验值：略大于"一次典型交互所需时间"，使切换开销占比低于 1%。

### 为什么说"不安全状态不一定死锁"？

银行家算法的安全序列是保守判断：找不到安全序列只说明没有保证能完成的调度次序，实际推进中若进程提前释放资源仍可能不死锁；但**死锁一定处于不安全状态**。

### 缺页率与页框数的普遍规律？

固定访问串下页框越多缺页率单调不升（FIFO 因 Belady 异常例外）。OPT/LRU 均满足包含性质，是考试默认假设。

### PV 操作写完怎么自查？

三个检查点：① 互斥信号量初值是否为 1、资源信号量是否等于资源数；② 多个 P 的顺序是否可能造成"持锁等资源"；③ 每个 P 是否有配对的 V 且路径覆盖所有分支。
