# 《数据结构》期末复习要点

> 面向武汉理工大学计算机类专业的《数据结构》课程期末复习提纲，覆盖核心考点、常见题型与易错点。

| 章节 | 核心考点 | 考试权重 |
|------|------|:---:|
| 线性表 | 顺序表与链表操作、复杂度分析 | 15% |

## 二、高频考点详解

### 1. 栈与队列

- 栈：后进先出（LIFO），主要应用有括号匹配、函数调用栈、表达式求值（中缀转后缀）。
- 队列：先进先出（FIFO），循环队列判空条件为 `front == rear`，判满条件为 `(rear + 1) % maxSize == front`。
- 易错点：循环队列牺牲一个存储单元来区分空和满。

### 2. 二叉树遍历

- 先序：根左右；中序：左根右；后序：左右根。
- 已知先序+中序可唯一确定二叉树；已知先序+后序不能唯一确定。
- 完全二叉树用顺序存储，第 i 个结点的左右孩子下标为 2i 和 2i+1。

### 3. 哈夫曼树

- 带权路径长度 WPL = 所有叶子结点权值 × 路径长度之和。
- 哈夫曼树是 WPL 最小的二叉树，构造过程为"每次取权值最小的两棵树合并"。
- n 个叶子结点的哈夫曼树共有 2n-1 个结点。

### 4. 图的最短路径

| 算法 | 适用场景 | 时间复杂度 |
|------|------|------|
| Dijkstra | 单源、边权非负 | O(V²) |
| Floyd | 所有顶点对 | O(V³) |
| Prim | 最小生成树（稠密图） | O(V²) |
| Kruskal | 最小生成树（稀疏图） | O(E log E) |

### 5. 排序算法对比

| 算法 | 平均时间复杂度 | 空间 | 稳定性 |
|------|:---:|:---:|:---:|
| 快速排序 | O(n log n) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 堆排序 | O(n log n) | O(1) | 不稳定 |
| 直接插入 | O(n²) | O(1) | 稳定 |
| 简单选择 | O(n²) | O(1) | 不稳定 |

## 三、常考题型

1. 选择题：概念辨析、复杂度计算、算法适用场景。
2. 填空题：遍历序列、哈希表冲突处理结果。
3. 应用题：哈夫曼编码、最小生成树、最短路径、拓扑排序。
4. 编程题：链表逆置、二叉树层序遍历、快速排序实现。

## 四、复习建议

1. 优先掌握树的遍历与图的搜索，这两个章节占分最高。
2. 排序算法建议自己手写一遍代码，注意稳定性与复杂度。
3. 结合课后习题与往年试卷练习，重点做应用题。
