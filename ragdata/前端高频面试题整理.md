# 前端高频面试题整理（八股文版）

> 汇总大厂前端面试中的高频基础题，按 HTML/CSS、JavaScript、框架、工程化四部分整理，附标准答案要点。

## 一、HTML 与 CSS

### 1. 盒模型

- 标准盒模型：width = content；IE 盒模型（border-box）：width = content + padding + border。
- 通过 `box-sizing: border-box` 让 IE 盒模型生效，布局更可控。

### 2. 水平垂直居中

```css
/* 方案一：flex */
.parent { display: flex; align-items: center; justify-content: center; }
/* 方案二：绝对定位 + transform */
.child { position: absolute; top: 50%; left: 50%; transform: translate(-50%, -50%); }
```

### 3. 回流（Reflow）与重绘（Repaint）

- 改变布局属性（宽高、边距、定位）触发回流；改变颜色、背景等仅触发重绘。
- 优化：批量修改 DOM、使用 `display:none` 后操作再显示、`will-change` 提示浏览器。

## 二、JavaScript

### 1. 事件循环（Event Loop）

- 宏任务：setTimeout、setInterval、I/O；微任务：Promise.then、MutationObserver、queueMicrotask。
- 执行顺序：同步代码 → 微任务 → 宏任务，宏任务执行完后会清空当前微任务队列。

### 2. 闭包

- 闭包 = 函数 + 函数定义时的词法环境。用于数据私有化、函数柯里化、防抖节流。
- 内存泄漏：闭包引用的大对象长期不被释放，可通过置空引用解决。

### 3. 防抖与节流

```js
// 防抖：触发后延迟执行，多次触发只执行最后一次
function debounce(fn, delay) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
// 节流：固定时间间隔内只执行一次
function throttle(fn, interval) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= interval) { last = now; fn.apply(this, args); }
  };
}
```

### 4. 原型链与 this

- `__proto__` 指向构造函数的 `prototype`，实例查找属性沿原型链向上。
- this 指向：普通函数调用指向调用者，箭头函数继承外层 this，new 绑定新对象。

## 三、Vue 相关

| 问题 | 答案要点 |
|------|------|
| Vue 2 与 Vue 3 响应式区别 | Vue2 用 Object.defineProperty，Vue3 用 Proxy，支持新增/删除属性 |
| computed 与 watch 区别 | computed 有缓存、依赖响应式数据；watch 监听变化执行副作用 |
| 虚拟 DOM 的作用 | 减少真实 DOM 操作，diff 算法（同层比较、key 优化）复用节点 |
| 组件通信方式 | props/emit、provide/inject、事件总线、Vuex/Pinia、$refs |

## 四、工程化与网络

1. **HTTP 缓存**：强缓存（Cache-Control: max-age）+ 协商缓存（ETag/Last-Modified）。
2. **跨域解决方案**：CORS、JSONP、代理服务器（webpack-dev-server proxy、nginx）。
3. **webpack 构建优化**：代码分割（Code Splitting）、Tree Shaking、loader 处理、缓存。

## 五、面试技巧

1. 八股题回答遵循"是什么→原理→应用场景→优缺点"四步结构。
2. 手写代码题先讲思路再写，注意边界条件（空数组、单元素）。
3. 不会的题诚实说明，并说出自己的思考方向。
