# 算法设计基础

## 1. 算法的定义与特性

**算法（Algorithm）**：对特定问题求解步骤的一种描述，是指令的有限序列。

**五大特性**：
1. **输入（input）**：有零个或多个输入
2. **输出（output）**：有一个或多个输出
3. **有穷性（finiteness）**：对于任何合法输入，算法必须在有穷时间内完成（程序可以无限循环，算法不可以）
4. **确定性（determinacy）**：每条指令有确切的含义，相同输入得到相同输出
5. **可行性（feasibility）**：每条指令可以通过已实现的基本操作执行有限次实现

> 欧几里得算法（辗转相除法）——求最大公约数的经典算法

## 2. 算法描述方法

| 方法 | 优点 | 缺点 | 使用场景 |
|------|------|------|----------|
| **自然语言** | 易书写、易理解 | 易二义性、冗长 | 粗线条描述算法思想 |
| **程序流程图** | 直观易懂 | 缺乏严密性 | 描述简单算法 |
| **伪代码** | 表达力强、抽象性强 | — | 自然语言+程序设计语言 |
| **程序设计语言** | 能由计算机执行 | 抽象性差 | 算法验证 |

## 3. 好算法的五大特性

1. **正确性（correctness）**：对任何合法输入得出正确结果
2. **健壮性（robustness）**：对非法输入有抵抗能力
3. **可读性（comprehensible）**：易理解、易转换为程序
4. **时间效率高**：运行时间短
5. **空间效率高**：额外存储空间尽量少

## 4. 算法设计的一般过程

**数学模型** → **算法设计** → **正确性证明** → **算法分析** → **算法实现**

## 5. 重要的问题类型

1. **查找问题（search）**：在大型数据集上高效查找
2. **排序问题（sort）**：没有一种排序在任何情况下都是最好的
3. **图问题（graph problem）**：很多现实问题抽象为图结构
4. **组合问题（combination problem）**：一般是最优化问题，存在**组合爆炸**
5. **几何问题（geometry problem）**：最近对问题、凸包问题

# 一、算法分析基础

## 1. 算法分析概述

**算法分析的两个方面**：
- **时间复杂度**：算法运行所需的时间资源
- **空间复杂度**：算法运行所需的空间资源

**分析方法**：
- **事后统计法**：编写程序统计执行时间（依赖软硬件环境）
- **事前分析估算法**：渐近分析法（只关注输入规模增大时的增长趋势）

## 2. 渐近复杂度分析

算法的运行时间是问题规模 n 的函数，记作 T(n)。用基本语句的执行次数 f(n) 表示 T(n)。

> **重要原则**：忽略低阶项和常系数，只考虑最高阶

### 三种渐近符号

| 符号 | 名称 | 含义 | 类比 |
|------|------|------|------|
| **O** (大O) | 渐近上界 | $T(n) \leq c \cdot g(n)$ | 最坏情况 |
| **Ω** (大Ω) | 渐近下界 | $T(n) \geq c \cdot g(n)$ | 最好情况 |
| **Θ** (大Θ) | 渐近紧界 | $c_1 \cdot g(n) \leq T(n) \leq c_2 \cdot g(n)$ | 精确阶 |

> **紧凑上界**：上界的阶越低，评估越准确
> **紧凑下界**：下界的阶越高，评估越准确
>
> 定理：若 $T(n)=a_m n^m + a_{m-1}n^{m-1} + ... + a_1 n + a_0$，则 $T(n)=\Theta(n^m)$

### 最好、最坏和平均情况

- **最好情况** $T_{min}(n)$：在所有输入下执行基本语句的最少次数
- **最坏情况** $T_{max}(n)$：在所有输入下执行基本语句的最大次数（最常用）
- **平均情况** $T_{avg}(n)$：概率加权平均

> 为什么通常用**最坏情况**（渐近上界 O）？
> 1. 给出了任何输入的运行时间上界
> 2. 对某些算法，最坏情况经常出现
> 3. "平均情况" 往往与最坏情况一样差

### 非递归算法复杂度分析步骤

1. 决定用哪个参数作为问题规模的度量
2. 找出算法中的**基本语句**（通常是最内层循环体）
3. 检查基本语句执行次数是否只依赖问题规模
4. 建立基本语句执行次数的**求和表达式**
5. 用**渐近符号**表示求和表达式

### 重要法则

- **加法法则**：$T_1(n)+T_2(n) = O(\max(f(n), g(n)))$
- **乘法法则**：$T_1(n) \cdot T_2(n) = O(f(n) \cdot g(n))$
- **对数幂**：$\log^k n \leq O(n)$（n 的增长快于 $\log n$ 的任意次幂）

## 3. 算法复杂性理论

| 类型 | 特点 | 常见阶 |
|------|------|--------|
| **多项式阶算法**（有效算法） | $T(n)=O(n^k)$ | $O(1) < O(\log n) < O(n) < O(n\log n) < O(n^2) < O(n^3)$ |
| **指数阶算法** | $T(n)=\Omega(a^n)$ | $O(2^n) < O(n!) < O(n^n)$ |

> **重要事实**：当代个人计算机 1s 内可做约 $10^8$ 次计算
>
> **核心结论**：硬件再强，也顶不住指数复杂度爆炸
> - O(n) 线性：n 翻 10 倍 → 时间翻 10 倍
> - O(n²) 平方：n 翻 10 倍 → 时间翻 100 倍
> - O(2ⁿ) 指数：n 每 +1 → 时间直接翻倍
> - n=60, O(2ⁿ) ≈ 36 年；n=80 ≈ 3800 万年

**NP Hard 问题**（典型难解问题）：
SAT问题、最大团问题、图着色问题、哈密顿回路问题、TSP问题、顶点覆盖问题、最长路径问题、子集和问题

## 4. 递归算法分析

### 递归方程的建立

```c
// 例：汉诺塔
void Hanoi(int n, char A, char B, char C) {
    if (n == 1) printf("将盘片从%c搬到%c\n", A, C);
    else {
        Hanoi(n-1, A, C, B);
        printf("将盘片%d从%c搬到%c\n", n, A, C);
        Hanoi(n-1, B, A, C);
    }
}
// 递归方程：T(n) = O(1) (n=1)；T(n) = 2T(n-1) + O(1) (n>1) ⇒ T(n)=O(2ⁿ)
```

### 递归方程的求解方法

#### (1) 迭代法
反复代入展开：
$$T(n) = 2T(n-1)+c = 2[2T(n-2)+c]+c = 2^{n-1}T(1)+c(2^{n-2}+...+2+1) = O(2^n)$$

$$T(n) = 2T(n/2)+cn = 2[2T(n/4)+cn/2]+cn = 2^k T(1) + kcn = n + cn\log n = O(n\log n)$$

#### (2) 代入法
猜测解的形式，用数学归纳法证明。

#### (3) 递归树法
展开递归方程构造递归树，每层代价求和，再对全部层求和。

#### (4) 主方法
适用于 $T(n) = aT(n/b) + f(n)$ 形式：

| 情况 | 条件 | 结论 |
|------|------|------|
| 1 | $f(n) < n^{\log_b a}$（多项式小于） | $T(n) = \Theta(n^{\log_b a})$ |
| 2 | $f(n) = n^{\log_b a}$（相等） | $T(n) = \Theta(n^{\log_b a} \log n)$ |
| 3 | $f(n) > n^{\log_b a}$（多项式大于） | $T(n) = \Theta(f(n))$ |

**示例**：
- $T(n)=4T(n/2)+n$：$n^{\log_2 4}=n^2$，情况1，$T(n)=O(n^2)$
- $T(n)=4T(n/2)+n^2$：$n^{\log_2 4}=n^2$，情况2，$T(n)=O(n^2\log n)$
- $T(n)=3T(n/3)+n^2$：$n^{\log_3 3}=n < n^2$，情况3，$T(n)=O(n^2)$

## 5. 空间复杂度分析

$S(n) = O(g(n))$，只考察**临时变量**所占空间（不计形参）。

- **原地工作（就地）**：辅助空间相对于问题规模是常数，$S(n)=O(1)$
- **递归空间复杂度**：递归深度 × 每次调用的空间
  - 递归求最大值：$S(n) = O(\log n)$（深度 $\log n$）
  - 归并排序：$S(n) = O(n)$（辅助数组）

# 二、分治法（Divide and Conquer）

## 0. 分治法概述

**设计思想**：将大问题划分成若干规模较小的子问题，分别求解各子问题，再合并子问题的解得到原问题的解。

**三个条件**：
1. 子问题与原问题性质相同
2. 子问题可彼此独立求解（不包含公共子问题）
3. 子问题规模缩小到一定程度可容易地直接求解

**三个阶段**：**划分** → **求解子问题** → **合并**

**一般算法框架**：
```
Divide_Conquer(P) {
    if (P的规模足够小) 直接求解P;
    else {
        分解为k个子问题P1, P2, ..., Pk;
        for (i=1; i<=k; i++) yi = Divide_Conquer(Pi);
        return Combine(y1, ..., yk);
    }
}
```

**启发式原则**：
1. **平衡子问题**：子问题规模最好大致相同
2. **各子问题相互独立**：若不独立，用动态规划法更好

**典型时间复杂度**：$T(n) = aT(n/b) + f(n)$，其中 a 为子问题个数，n/b 为子问题规模，f(n) 为划分+合并时间。

## 1. 二分查找 (Binary Search)

### 问题描述
在有序数组 R[low..high] 中查找值为 k 的元素，若找到返回其下标，否则返回 -1。

### 算法思想
在有序数组中，每次取中间元素与待查找关键字比较，缩小一半查找区间，递归进行。

### 伪代码
```c
int BinSearch(int R[], int low, int high, int k) {
    int mid;
    if (low <= high) {                              // 查找区间非空
        mid = (low + high) / 2;                     // 取中间位置
        if (R[mid] == k) return mid;                // 找到目标，返回下标
        if (R[mid] > k)                             // 目标在左半区间
            return BinSearch(R, low, mid - 1, k);
        else                                        // 目标在右半区间
            return BinSearch(R, mid + 1, high, k);
    }
    else return -1;                                 // 查找失败
}
```

### 时间复杂度
$$T(n) = T(n/2) + O(1) \Rightarrow T(n) = O(\log n)$$

### 注意要点
- **要求**：数组必须有序
- 属于**减治法**（每次只需处理一个子问题，不合并）

## 2. 快速排序 (QuickSort)

### 问题描述
对无序序列 r[s..t] 按非降序进行原地排序。

### 算法思想
选一个基准值，将序列划分成两个子序列（左小右大），再递归对子序列排序。

### 伪代码
```c
void QuickSort(int r[], int s, int t) {
    if (s < t) {                                // 区间至少有两个元素
        int i = Partition(r, s, t);             // 划分，返回基准最终位置
        QuickSort(r, s, i-1);                   // 递归排序左半区间
        QuickSort(r, i+1, t);                   // 递归排序右半区间
    }
}

int Partition(int r[], int s, int t) {
    int i = s, j = t;
    int tmp = r[s];                             // 以第一个元素为基准
    while (i < j) {
        while (i < j && r[j] >= tmp) j--;       // 从右向左找第一个小于tmp的
        if (i < j) { r[i] = r[j]; i++; }        // 将其填到左边空位
        while (i < j && r[i] <= tmp) i++;       // 从左向右找第一个大于tmp的
        if (i < j) { r[j] = r[i]; j--; }        // 将其填到右边空位
    }
    r[i] = tmp;                                 // 将基准放入最终位置
    return i;                                   // 返回基准下标
}
```

### 时间复杂度
| 情况 | 时间复杂度 |
|------|-----------|
| **最好/平均** | $O(n \log n)$ |
| **最坏**（已有序） | $O(n^2)$ |

- 划分阶段 $D(n)=O(n)$，合并 $C(n)=O(1)$
- 最好递归方程：$T(n) = 2T(n/2) + O(n)$
- 空间复杂度：平均 $O(\log n)$

## 3. 归并排序 (MergeSort)

### 问题描述
对无序序列 r[s..t] 按非降序进行稳定排序。

### 算法思想
将序列从中间分成两半，分别排序后合并两个有序子序列。

### 伪代码
```c
void MergeSort(int r[], int s, int t) {
    if (s == t) return;                         // 区间只有一个元素，自然有序
    int m = (s + t) / 2;                        // 取中间点划分
    MergeSort(r, s, m);                         // 归并排序左半部分
    MergeSort(r, m+1, t);                       // 归并排序右半部分
    Merge(r, s, m, t);                          // 合并两个有序子序列
}

void Merge(int r[], int s, int m, int t) {
    int r1[t], i = s, j = m+1, k = s;           // r1为辅助数组
    while (i <= m && j <= t) {                  // 两路归并
        if (r[i] <= r[j]) r1[k++] = r[i++];     // 取左边较小者
        else r1[k++] = r[j++];                  // 取右边较小者
    }
    while (i <= m) r1[k++] = r[i++];            // 复制左边剩余元素
    while (j <= t) r1[k++] = r[j++];            // 复制右边剩余元素
    for (i = s; i <= t; i++) r[i] = r1[i];      // 将辅助数组写回原数组
}
```

### 时间复杂度
$$T(n) = 2T(n/2) + O(n) \Rightarrow T(n) = O(n \log n)$$

- 空间复杂度：$S(n) = O(n)$（辅助数组）

## 4. 查找第 k 小元素（选择问题）

### 问题描述
在无序序列 r[low..high] 中找出第 k 小（第 k 大）的元素，不要求对整个序列排序。

### 算法思想
基于快排划分：以基准值划分后，根据基准位置 s 与 k 的关系，决定在左半或右半继续查找。

### 伪代码
```c
int SelectMinK(int r[], int low, int high, int k) {
    int s = Partition(r, low, high);                // 划分，返回基准位置
    if (s == k) return r[s];                        // 基准恰好是第k小
    if (s > k) return SelectMinK(r, low, s-1, k);   // 第k小在左半区间
    else return SelectMinK(r, s+1, high, k);        // 第k小在右半区间
}
```

### 时间复杂度
| 情况 | 时间复杂度 |
|------|-----------|
| **最好/平均** | $O(n)$ |
| **最坏** | $O(n^2)$ |

> 线性时间选择算法（Blum et al.）可保证 $O(n)$

## 5. Top K 问题（最大的前 k 个数）

### 问题描述
在含有 n 个元素的序列 a[0..n-1] 中找出最大的前 k 个数，其中 k 远小于 n。

### 算法思想
用前 k 个元素构建**小顶堆**（极小优先队列），遍历剩余元素：若大于堆顶则替换并调整堆。

### 伪代码
```c
void MaxTopK(int a[], int n, int k, int max[]) {
    int i, j, par, child;
    // 构建小顶堆
    for (i = 0; i < k; i++) {
        max[i] = a[i];
        // 向上调整
        for (j = i; j > 0; ) {
            par = (j-1)/2;
            if (max[j] > max[par]) break;
            else { int tmp = max[j]; max[j] = max[par]; max[par] = tmp; j = par; }
        }
    }
    // 处理剩余元素
    for ( ; i < n; i++) {
        if (a[i] <= max[0]) continue;       // 丢弃
        max[0] = a[i];
        // 向下调整
        j = 0; child = 2*j + 1;
        while (child < k) {
            if (child+1 < k && max[child] > max[child+1]) child++;
            if (max[j] < max[child]) break;
            else { int tmp = max[j]; max[j] = max[child]; max[child] = tmp; j = child; child = 2*j+1; }
        }
    }
}
```

### 时间复杂度
$$T(n) = O(n \log k)$$

空间复杂度 $O(k)$。

## 6. 最大子段和问题

### 问题描述
给定整数序列 a[0..n-1]（可能含负数），求连续子段的最大和。即求 $\max\{\sum_{k=i}^j a[k] \mid 0 \leq i \leq j < n\}$。

### 算法思想（在线处理法）
扫描数组，用 sum 记录当前子序列和，若 sum < 0 则舍弃重新开始，用 max 记录最大和。

### 伪代码
```c
int maxSubSum(int a[], int n) {
    int i, max = 0, sum = 0;
    for (i = 0; i < n; i++) {
        sum += a[i];                // 将当前元素加入子段
        if (sum < 0) sum = 0;       // 子段和为负则舍弃，重新开始
        if (sum > max) max = sum;   // 更新最大子段和
    }
    return max;
}
```

### 时间复杂度
$$T(n) = O(n)$$

> 分治解法也可行：$T(n) = 2T(n/2) + O(n) \Rightarrow O(n \log n)$，但不如在线处理法

## 7. 寻找两个等长有序序列的中位数（实验）

### 问题描述
给定两个长度均为 n 的有序序列 X 和 Y，求它们合并后的中位数（第 n 小元素），要求时间复杂度优于 $O(n)$。

### 算法思想
每次比较两个序列的中位数，根据大小关系舍弃一半元素，逐步缩小查找区间。

### 伪代码
```c
double findMedian(int X[], int l1, int r1, int Y[], int l2, int r2) {
    int len = r1 - l1 + 1, m1 = (l1+r1)/2, m2 = (l2+r2)/2;

    if (len == 1) return (X[l1] + Y[l2]) / 2.0;         // 每个序列只剩一个元素
    if (len == 2) {                                      // 各剩两个元素，取4个中中间两个
        int t[4] = {X[l1], X[r1], Y[l2], Y[r2]};
        // 对 4 个元素做简单排序（冒泡即可）
        for (int p = 0; p < 4; p++)
            for (int q = p + 1; q < 4; q++)
                if (t[p] > t[q]) { int tmp = t[p]; t[p] = t[q]; t[q] = tmp; }
        return (t[1] + t[2]) / 2.0;
    }
    if (X[m1] == Y[m2]) return X[m1];                   // 中位数相等即结果
    if (X[m1] < Y[m2])                                  // X中位数较小，舍弃X左半+Y右半
        return findMedian(X, m1+1, r1, Y, l2, m2);
    else                                                // Y中位数较小，舍弃Y左半+X右半
        return findMedian(X, l1, m1, Y, m2+1, r2);
}
```

### 时间复杂度
$$T(n) = O(\log n)$$

## 8. Gray 码（实验）

### 问题描述
生成 n 位格雷码（Gray Code），使相邻两个编码只有一位二进制不同，且首尾编码也只有一位不同（循环码）。常用于数字通信减少传输错误。

### 算法思想
递归构造：n 位 Gray 码 = (n-1 位 Gray 码前加 '0') + (n-1 位 Gray 码逆序前加 '1')。

### 伪代码
```c
// 递归构造 n 位 Gray 码，结果存入 gray 数组
void GrayCode(int n, string gray[]) {
    if (n == 1) {
        gray[0] = "0";
        gray[1] = "1";
        return;
    }
    int len = 1 << (n - 1);          // 前半部分长度
    GrayCode(n - 1, gray);           // 递归构造 n-1 位 Gray 码

    // 前半部分前加 '0'
    for (int i = len - 1; i >= 0; i--)
        gray[2 * len - 1 - i] = "1" + gray[i];
    for (int i = 0; i < len; i++)
        gray[i] = "0" + gray[i];
}

// 非递归法（更简洁，利用 G(n) = n ^ (n >> 1)）
void GrayCodeIter(int n) {
    for (int i = 0; i < (1 << n); i++) {
        int g = i ^ (i >> 1);        // 第 i 个 Gray 码的二进制值
        // 输出 g 的 n 位二进制表示
        for (int k = n - 1; k >= 0; k--)
            printf("%d", (g >> k) & 1);
        printf("\n");
    }
}
```

### 时间复杂度
$$T(n) = 2T(n-1) + O(2^{n-1}) \Rightarrow T(n) = O(2^n)$$

## 9. 棋盘覆盖问题

### 问题描述
$2^k \times 2^k$ 棋盘有一个特殊方格，用 4 种 L 型三格骨牌覆盖其余方格。

### 分治思想
将棋盘四等分，在无特殊方格的象限中放置一个三格骨牌（制造"人工"特殊方格），递归处理每个象限。

### 伪代码
```c
#define MAXN 1024
int board[MAXN][MAXN];               // 棋盘
int tile = 1;                        // 骨牌编号（从 1 开始）

// tr, tc: 棋盘左上角坐标；dr, dc: 特殊方格坐标；size: 棋盘大小（2^k）
void ChessBoard(int tr, int tc, int dr, int dc, int size) {
    if (size == 1) return;
    int t = tile++;                  // 当前 L 型骨牌编号
    int s = size / 2;                // 分割棋盘

    // 1. 左上象限
    if (dr < tr + s && dc < tc + s)  // 特殊方格在此象限
        ChessBoard(tr, tc, dr, dc, s);
    else {                           // 无特殊方格，右下角置为骨牌
        board[tr + s - 1][tc + s - 1] = t;
        ChessBoard(tr, tc, tr + s - 1, tc + s - 1, s);
    }

    // 2. 右上象限
    if (dr < tr + s && dc >= tc + s)
        ChessBoard(tr, tc + s, dr, dc, s);
    else {
        board[tr + s - 1][tc + s] = t;
        ChessBoard(tr, tc + s, tr + s - 1, tc + s, s);
    }

    // 3. 左下象限
    if (dr >= tr + s && dc < tc + s)
        ChessBoard(tr + s, tc, dr, dc, s);
    else {
        board[tr + s][tc + s - 1] = t;
        ChessBoard(tr + s, tc, tr + s, tc + s - 1, s);
    }

    // 4. 右下象限
    if (dr >= tr + s && dc >= tc + s)
        ChessBoard(tr + s, tc + s, dr, dc, s);
    else {
        board[tr + s][tc + s] = t;
        ChessBoard(tr + s, tc + s, tr + s, tc + s, s);
    }
}
```

### 时间复杂度
$$T(k) = 4T(k-1) + O(1) \Rightarrow T(k) = O(4^k)$$

# 三、动态规划（Dynamic Programming）

## 0. 动态规划概述

### 基本概念
- **多阶段决策过程**：一个决策序列在不断变化的状态中产生的过程
- **最优化问题**：有 n 个输入，解由 n 个输入的一个子集组成，满足约束条件并使目标函数取极值
- **阶段**：将求解过程划分的若干相互联系的阶段
- **状态**：描述决策过程当前特征的量
- **决策与策略**：从某一状态做出的选择，策略是决策的序列

### 三大要素
1. **最优子结构（最优性原理）**：问题的最优解包含子问题的最优解（用反证法证明）
2. **重叠子问题**：子问题之间不独立，在下一阶段决策中可能被多次使用
3. **无后效性（马尔科夫性）**：某阶段状态一旦确定，不受以后决策的影响

### 动态规划与分治法的比较
| 对比维度 | 分治法 | 动态规划 |
|---------|-------|---------|
| 子问题关系 | 相互独立 | 一般相互重叠 |
| 重复求解 | 可能重复求解，效率低 | 每个子问题只求解一次，填表保存 |
| 典型应用 | 二分查找、快排 | 背包、LCS、LIS |

### 求解步骤
1. **划分子问题**：分析最优解的结构特征
2. **确定动态规划函数**：建立递推关系式（关键）
3. **填写表格**：自底向上或自顶向下（备忘录）计算
4. **构造最优解**：根据记录的决策信息回溯

### 两种实现方法
| 方法 | 方向 | 特点 |
|------|------|------|
| **自底向上（动态规划）** | 从初始状态开始递推 | 所有子问题至少求解一次时较好 |
| **自顶向下（备忘录方法）** | 递归+查表 | 部分子问题不需要求解时较好 |

---

## 1. 多段图的最短路径问题

### 问题描述
给定一个多段图（按阶段划分的有向无环图），求从源点 s 到终点 t 的最短路径长度及路径。

### 算法思想
从源点出发逐阶段递推，$dp[j]$ 表示从源点 s 到顶点 j 的最短路径长度。

**状态转移方程**：
$$dp[j] = \min\{dp[i] + c_{ij}\} \quad (i, j) \in E$$

### 解法分类
- **顺序解法**：从第 1 阶段到第 k 阶段，$f(s)$ 表示从起点到当前状态 s 的最短路径
- **逆序解法**：从第 k 阶段到第 1 阶段，$f(s)$ 表示从当前状态 s 到终点的最短路径

### 伪代码
```c
int MultistageG(int n) {
    int path[N], dp[N];
    for (i = 0; i < n; i++) { dp[i] = MAX; path[i] = -1; }  // 初始化
    dp[0] = 0;                                  // 源点到自身的距离为0

    for (i = 1; i < n; i++) {                   // 逐顶点递推最短路径
        for (j = i - 1; j >= 0; j--) {          // 检查所有前驱顶点
            if (arc[j][i] + dp[j] < dp[i]) {    // 经j中转比当前更短
                dp[i] = arc[j][i] + dp[j];      // 更新最短距离
                path[i] = j;                    // 记录前驱顶点
            }
        }
    }
    // 输出最短路径（逆序打印）
    cout << n - 1;
    i = n - 1;
    while (path[i] >= 0) {
        cout << "<-" << path[i];
        i = path[i];
    }
    return dp[n - 1];
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

## 2. 数塔问题

### 问题描述
给定一个 n 层数字三角形（数塔），从顶层到底层每次只能走下一层相邻的结点，求一条路径使经过的数字之和最大。

### 算法思想
自底向上递推，$dp[i][j]$ 表示从位置 $(i,j)$ 到底边的最大路径和。

**动态规划函数**：
$$dp[i][j] = \max\{dp[i+1][j],\; dp[i+1][j+1]\} + a[i][j]$$

### 伪代码
```c
int TowerDP(int a[N][N], int dp[N][N], int next[N][N], int n) {
    for (int i = 0; i < n; i++) dp[n-1][i] = a[n-1][i];    // 底层初始化：到底路径即自身值
    for (int i = n-2; i >= 0; i--) {                        // 从倒数第二层向上递推
        for (int j = 0; j <= i; j++) {
            if (dp[i+1][j] > dp[i+1][j+1]) {                // 左下方路径和更大
                dp[i][j] = dp[i+1][j] + a[i][j];
                next[i][j] = j;                             // 记录路径：往左下走
            } else {                                        // 右下方路径和更大
                dp[i][j] = dp[i+1][j+1] + a[i][j];
                next[i][j] = j + 1;                         // 记录路径：往右下走
            }
        }
    }
    // 输出最优路径
    int cur = 0;
    for (int i = 0; i < n; i++) {
        printf("%d ", cur);
        cur = next[i][cur];                                 // 沿记录路径移动
    }
    return dp[0][0];
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

### 备忘录方法
```c
int MaxSum(int i, int j) {
    if (dp[i][j] != -1) return dp[i][j];      // 查表：已计算过则直接返回
    if (i == n-1) dp[i][j] = a[i][j];          // 底层：到底路径即自身值
    else {
        int x = MaxSum(i+1, j);                // 递归求左下方最大路径和
        int y = MaxSum(i+1, j+1);              // 递归求右下方最大路径和
        dp[i][j] = max(x, y) + a[i][j];        // 取较大者加当前值
    }
    return dp[i][j];                           // 返回并记录到表中
}
```

## 3. 最长递增子序列问题（LIS）

### 问题描述
给定序列 $a[0..n-1]$，求其最长递增（非降）子序列的长度。子序列不要求连续，但元素在原序列中的相对顺序不变。

### 算法思想
$dp[i]$ 表示以 $a[i]$ 结尾的最长递增子序列长度。

**动态规划函数**：
$$dp[i] = \max\{1,\; \max\{dp[j]+1 \;|\; a[i] > a[j],\; 0 \leq j < i\}\}$$

**原问题解**：$\max\{dp[i]\;|\; 0 \leq i < n\}$

### 伪代码
```c
void solve(int a[], int n) {
    for (i = 0; i < n; i++) {
        dp[i] = 1;                          // 至少包含自身，长度为1
        for (j = 0; j < i; j++)
            if (a[i] > a[j])                // 可将a[i]接在a[j]后面
                dp[i] = max(dp[i], dp[j] + 1);
    }
    ans = dp[0];
    for (i = 1; i < n; i++)
        ans = max(ans, dp[i]);              // 取所有dp[i]的最大值
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

> 可优化至 $O(n \log n)$（贪心+二分）

## 4. 最长公共子序列问题（LCS）

### 问题描述
给定两个序列 $X$ 和 $Y$，求它们的最长公共子序列的长度及该子序列。公共子序列指同时是 $X$ 和 $Y$ 子序列的序列。

### 算法思想
$dp[i][j]$ 表示 $X[1..i]$ 和 $Y[1..j]$ 的最长公共子序列长度。

**动态规划函数**：
$$dp[i][j] = \begin{cases}
0 & i=0 \text{ 或 } j=0 \\
dp[i-1][j-1] + 1 & X_i = Y_j \\
\max(dp[i][j-1],\; dp[i-1][j]) & X_i \neq Y_j
\end{cases}$$

### 伪代码
```c
void LCSlength() {
    for (i = 0; i <= m; i++) dp[i][0] = 0;      // 初始化：空序列与任意序列的LCS为0
    for (j = 0; j <= n; j++) dp[0][j] = 0;
    for (i = 1; i <= m; i++)
        for (j = 1; j <= n; j++) {
            if (x[i-1] == y[j-1])               // 两字符相等，LCS长度+1
                dp[i][j] = dp[i-1][j-1] + 1;
            else                                // 不等，取两种情况的最大值
                dp[i][j] = max(dp[i][j-1], dp[i-1][j]);
        }
}

void Buildsubs() {                               // 回溯构造LCS
    int k = dp[m][n], i = m, j = n;
    while (k > 0) {
        if (dp[i][j] == dp[i-1][j]) i--;         // 来自上方，X[i]不在LCS中
        else if (dp[i][j] == dp[i][j-1]) j--;    // 来自左方，Y[j]不在LCS中
        else {                                   // 来自左上角，X[i]=Y[j]在LCS中
            subs.push_back(x[i-1]);
            i--; j--; k--;
        }
    }
}
```

### 时间复杂度
$$T(n) = O(mn)$$

**应用**：论文查重（检测文字雷同）

## 5. 0/1 背包问题

### 问题描述
给定 n 个物品，每个物品 i 有重量 $w[i]$ 和价值 $v[i]$，背包容量为 C。每个物品要么取走要么不取（不能拆分），求不超过背包容量的最大总价值。

### 算法思想
$dp[i][r]$ 表示前 i 个物品在背包容量为 r 时的最大价值。

**动态规划函数**：
$$dp[i][r] = \begin{cases}
0 & i=0 \text{ 或 } r=0 \\
dp[i-1][r] & w[i] > r \\
\max(dp[i-1][r],\; dp[i-1][r-w[i]] + v[i]) & w[i] \leq r
\end{cases}$$

### 伪代码
```c
void Knapsack() {
    for (i = 0; i <= n; i++) dp[i][0] = 0;      // 容量为0时价值为0
    for (r = 0; r <= C; r++) dp[0][r] = 0;      // 没有物品时价值为0
    for (i = 1; i <= n; i++) {
        for (r = 1; r <= C; r++) {
            if (r < w[i])                        // 物品i超出当前容量，不能放入
                dp[i][r] = dp[i-1][r];
            else                                 // 选"不放入"和"放入"的较大者
                dp[i][r] = max(dp[i-1][r], dp[i-1][r-w[i]] + v[i]);
        }
    }
}

void Buildx() {                                  // 回溯构造最优解向量
    int i = n, r = C; maxv = 0;
    while (i >= 0) {
        if (dp[i][r] != dp[i-1][r]) {            // 选了物品i（价值增加）
            x[i] = 1; maxv += v[i]; r = r - w[i];
        } else x[i] = 0;                         // 没选物品i
        i--;
    }
}
```

### 时间复杂度
$$T(n) = O(n \times C)$$

> 空间优化：可用滚动数组将 dp 从 $O(n \times C)$ 降为 $O(C)$

## 6. 最大 k 乘积问题（实验）

### 问题描述
给定一个 n 位数字串，在其中插入 k-1 个乘号，将其分成 k 段，使这 k 段整数的乘积最大。

### 算法思想
$dp[i][t]$ 表示前 i 位数字切分成 t 段的最大乘积。

**状态转移**：
$$dp[i][t] = \max\{dp[m][t-1] \times num[m+1][i]\}$$

### 伪代码
```c
#define MAXN 20
typedef long long ll;

// num[i][j]: 数字串第 i 位到第 j 位组成的整数（如 digits="123", num[1][3]=123）
ll maxKProduct(char digits[], int n, int k) {
    ll num[MAXN][MAXN] = {0};
    ll dp[MAXN][MAXN] = {0};

    // 预处理：将连续数字位转换为整数值
    for (int i = 1; i <= n; i++) {
        num[i][i] = digits[i - 1] - '0';               // 单独一位
        for (int j = i + 1; j <= n; j++)
            num[i][j] = num[i][j - 1] * 10 + (digits[j - 1] - '0');  // 向左扩展一位
    }

    // 初始化：前 i 位分成 1 段（即整个数本身）
    for (int i = 1; i <= n; i++)
        dp[i][1] = num[1][i];

    // 动态规划
    for (int t = 2; t <= k; t++)               // 枚举分段数 t
        for (int i = t; i <= n; i++)            // 前 i 位数字
            for (int m = t - 1; m < i; m++)     // 枚举最后一个乘号的位置 m
                if (dp[m][t - 1] * num[m + 1][i] > dp[i][t])
                    dp[i][t] = dp[m][t - 1] * num[m + 1][i];  // 更新最大值

    return dp[n][k];                            // 前n位分成k段的最大乘积
}
```

### 时间复杂度
$$T(n) = O(k \cdot n^2)$$

## 7. 游艇租用问题（实验）

### 问题描述
有 n 个游艇租赁站点，$r[i][j]$ 表示从站点 i 直接到站点 j 的租金（$i < j$）。可经任意中转站点，求从站点 1 到站点 n 的最小租金。

### 算法思想
$dp[j]$ 表示从站点 1 到站点 j 的最小租金。

**状态转移**：
$$dp[j] = \min\{dp[i] + r[i][j]\}$$

### 伪代码
```c
#define MAXN 200
#define INF 0x3f3f3f3f

int yachtRent(int r[MAXN][MAXN], int n) {
    int dp[MAXN];
    dp[1] = 0;                                   // 站点1到自身距离为0
    for (int j = 2; j <= n; j++) {
        dp[j] = r[1][j];                         // 初始化：从站点1直达站点j
        for (int i = 2; i < j; i++)              // 尝试在中途站点i中转
            if (dp[i] + r[i][j] < dp[j])         // 经i中转比当前路径更短
                dp[j] = dp[i] + r[i][j];         // 更新最短距离
    }
    return dp[n];
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

## 8. TSP 问题（动态规划法）

### 问题描述
旅行商问题：给定 n 个城市及城市间的距离矩阵 G，旅行商从城市 0 出发，每个城市恰好访问一次后返回城市 0，求最短回路长度。

### 算法思想
$d(i, V')$ 表示从顶点 i 出发经过 $V'$ 中各顶点一次且仅一次，最后回到出发点 0 的最短路径长度。

**动态规划函数**：
$$d(i, V') = \min\{c_{ik} + d(k, V'-\{k\})\} \quad k \in V'$$

**初始状态**：
$$d(k, \{\}) = c_{k0}$$

### 伪代码
```c
#define MAXN 20
#define INF 0x3f3f3f3f

int dp[1 << MAXN][MAXN];                  // dp[mask][i]: 从0出发经过mask集合到达i的最短路径

int TSP_DP(int G[MAXN][MAXN], int n) {
    memset(dp, 0x3f, sizeof(dp));           // 按字节填充 0x3f，使每个 int 元素为 0x3f3f3f3f(=INF)
    dp[1][0] = 0;                         // 只访问了起点 0

    for (int mask = 1; mask < (1 << n); mask += 2) {  // mask 必须包含起点 0
        for (int i = 0; i < n; i++) {
            if (!(mask & (1 << i))) continue;          // i 不在当前集合中
            if (dp[mask][i] == INF) continue;

            for (int j = 0; j < n; j++) {
                if (mask & (1 << j)) continue;          // j 已访问过
                int newMask = mask | (1 << j);
                dp[newMask][j] = min(dp[newMask][j], dp[mask][i] + G[i][j]);
            }
        }
    }

    int ans = INF;
    for (int i = 1; i < n; i++)
        ans = min(ans, dp[(1 << n) - 1][i] + G[i][0]);   // 回到起点
    return ans;
}
```

### 时间复杂度
$$T(n) = O(2^n \cdot n^2)$$

> 比蛮力法的 $O(n!)$ 有显著改进，但仍是指数阶。

# 四、贪心法（Greedy Algorithm）

## 0. 贪心法概述

### 基本思想
把复杂问题分解为一系列局部最优选择，每一步选择都是对当前解的一个扩展，直至获得完整解。

> 贪心算法不一定能产生全局最优解，需严格证明。

### 两大性质（贪心法产生最优解的条件）
1. **贪心选择性质**：全局最优解可以通过局部最优选择得到
2. **最优子结构性质**：问题的最优解包含子问题的最优解

### 贪心选择性质证明方法
1. 假设存在问题的全局最优解 X
2. 证明可将 X 修改为从贪心选择开始（替换法）
3. 用数学归纳法证明：总存在以贪心选择开始的求解方案

### 与动态规划的比较
| 对比维度 | 动态规划 | 贪心法 |
|---------|---------|--------|
| 求解方向 | 自底向上 | 自顶向下 |
| 决策依据 | 依赖子问题的解 | 仅根据当前信息 |
| 适用性质 | 最优子结构+重叠子问题 | 最优子结构+贪心选择性质 |

### 一般求解过程
1. **划分子问题**：划分为连续的决策阶段
2. **贪心选择**：每阶段依据贪心策略做决策
3. **合并**：将各阶段的局部最优解合并

### 算法框架
```
SolutionType Greedy(SType C[], int n) {
    SolutionType X = {};
    while (!Solution(X)) {
        xi = Select(C);           // 贪心选择
        if (Feasiable(xi))
            X = X + {xi};
        C = C - {Collection(xi)}; // 缩小问题规模
    }
    return X;
}
```

**五个要素**：候选集合 C、解集合 X、选择函数 Select（关键）、可行函数 Feasible、解决函数 Solution

## 1. 付款问题

### 问题描述
给定各种面额的货币（人民币）及应付款金额，用最少的货币张数凑齐该金额。

### 贪心策略
在不超过应付款金额的条件下，选择面值最大的货币。

### 示例
找给顾客 4 元 6 角：**2 元 → 2 元 → 5 角 → 1 角**（最优解）

### 伪代码
```c
// money[] 已按面值降序排列，如 {100, 50, 20, 10, 5, 1}（单位：元，可扩展到角）
// count[i] 记录第 i 种面值使用的张数
void Pay(int money[], int n, int amount, int count[]) {
    for (int i = 0; i < n; i++) count[i] = 0;     // 初始化各面值张数为 0
    int i = 0;
    while (amount > 0 && i < n) {
        if (money[i] <= amount) {                  // 当前面值能用于找零
            int use = amount / money[i];           // 该面值最多用几张
            count[i] = use;
            amount -= use * money[i];              // 扣除已凑金额
        }
        i++;                                       // 换更小面值
    }
    if (amount > 0) printf("无法精确找零\n");
}
```

### 时间复杂度
$$T(n) = O(n)$$（n 为货币面额种类数，与金额大小无关）

> **注意**：人民币面额体系（1、2、5、10、20、50、100）具有"贪心选择性质"，贪心法可得最优解；但对任意面额组合（如 {1, 3, 4} 凑 6）贪心法不一定最优，需用动态规划。

## 2. 部分背包问题

### 问题描述
物品可拆分（取一部分装入背包），求不超过背包容量的最大价值。

### 贪心策略
选择**单位重量价值最大**的物品优先装入。

### 伪代码
```c
// 假设物品已按单位重量价值降序排列
double KnapSack(int w[], int v[], int n, int C) {
    double x[n] = {0}, maxValue = 0;
    int i;
    for (i = 0; w[i] < C; i++) {          // 整件装入，直到背包装不下完整物品
        x[i] = 1;                          // 标记第i个物品全部装入
        maxValue += v[i];                  // 累加价值
        C = C - w[i];                      // 更新剩余容量
    }
    x[i] = (double)C / w[i];               // 最后一件按比例部分装入
    maxValue += x[i] * v[i];               // 按比例增加价值
    return maxValue;
}
```

### 时间复杂度
$$T(n) = O(n \log n)$$（排序占主导）

> **与 0/1 背包的区别**：0/1 背包物品不可拆分，贪心法不能保证最优解，需用动态规划。

## 3. 活动安排问题（区间问题）

### 问题描述
有 n 个活动，每个活动 i 有开始时间 $s[i]$ 和结束时间 $f[i]$。同一时间一个活动只能使用一个资源，求能安排的最大活动数量（活动互不相容）。

### 贪心策略
按结束时间**非减序**排序，每次选择**最早结束**的相容活动。

### 伪代码
```c
// 假设 s[n]、f[n] 已按结束时间非降序排列
int ActiveManage(int s[], int f[], int B[], int n) {
    int i, j, count;
    B[0] = 1; j = 0; count = 1;                  // 选择第一个活动
    for (i = 1; i < n; i++) {
        if (s[i] >= f[j]) {                       // 活动i与已选最后一个活动相容
            B[i] = 1; count++; j = i;             // 选择活动i，更新最后结束时间
        } else B[i] = 0;                          // 冲突，不选
    }
    return count;
}
```

### 时间复杂度
$$T(n) = O(n \log n)$$（排序）+ $O(n)$（选择）

## 4. 多机调度问题

### 问题描述
有 n 个作业（每个作业处理时间为 $t[i]$）和 m 台相同的机器。每个作业只能在一台机器上处理且不可中断，求最短的完成时间（makespan）。

### 贪心策略
**最长处理时间作业优先**：把处理时间最长的作业分配给最先空闲的机器。

### 伪代码
```c
#define MAXN 1000
#define MAXM 100

// 作业已按处理时间降序排列
int MultiMachine(int t[], int n, int m) {
    int machine[MAXM] = {0};       // 每台机器的总处理时间
    int schedule[MAXM][MAXN];      // 每台机器上的作业分配
    int count[MAXM] = {0};         // 每台机器上的作业数

    // 前 m 个作业分配给 m 台机器
    for (int i = 0; i < m && i < n; i++) {
        machine[i] = t[i];
        schedule[i][count[i]++] = i;
    }

    // 剩余作业分配给最先空闲的机器
    for (int i = m; i < n; i++) {
        // 找最先空闲的机器（当前总耗时最小）
        int idx = 0;
        for (int j = 1; j < m; j++)
            if (machine[j] < machine[idx]) idx = j;
        machine[idx] += t[i];
        schedule[idx][count[idx]++] = i;
    }

    // 返回最大完工时间（所有机器中的最大值）
    int maxTime = machine[0];
    for (int i = 1; i < m; i++)
        if (machine[i] > maxTime) maxTime = machine[i];
    return maxTime;
}
```

### 时间复杂度
$$T(n) = O(n \log n + nm)$$

> 若用优先队列维护机器空闲时间，可优化至 $O(n \log m)$

## 5. 图着色问题（贪心法）

### 问题描述
给定无向连通图 G 和若干种颜色，为每个顶点着色，使相邻顶点颜色不同，求最少使用多少种颜色（贪心法给出近似解）。

### 贪心策略
选择一种颜色，为尽可能多的顶点着色（不冲突），再换下一种颜色。

### 伪代码
```c
#define MAXN 100

void GreedyColor(int G[MAXN][MAXN], int n, int color[]) {
    for (int i = 1; i <= n; i++) color[i] = 0;

    for (int i = 1; i <= n; i++) {
        int used[MAXN] = {0};
        // 标记相邻顶点已使用的颜色
        for (int j = 1; j <= n; j++)
            if (G[i][j] && color[j] != 0)
                used[color[j]] = 1;
        // 选最小的未使用颜色
        for (int c = 1; c <= n; c++)
            if (!used[c]) { color[i] = c; break; }
    }
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

> **注意**：贪心法求解图着色问题不一定得到最优解，结果受顶点顺序影响。

## 6. TSP 问题（贪心法）

### 问题描述
旅行商问题：给定 n 个城市及城市间的距离，求一条经过所有城市各一次后返回起点的最短回路。贪心法用于求近似解。

### 策略一：最近邻点策略
从任意城市出发，每次选择未到过的**最近**城市，直至全部到达后返回。

```c
#define MAXN 100
#define INF 0x3f3f3f3f

int TSP_Nearest(int G[MAXN][MAXN], int n) {
    int visited[MAXN] = {0}, path[MAXN];
    int total = 0, cur = 1;         // 从城市 1 出发
    visited[cur] = 1;
    path[0] = cur;

    for (int t = 1; t < n; t++) {
        int next = -1, minDist = INF;
        for (int j = 1; j <= n; j++)
            if (!visited[j] && G[cur][j] < minDist) {
                minDist = G[cur][j];
                next = j;
            }
        total += minDist;
        visited[next] = 1;
        path[t] = next;
        cur = next;
    }
    total += G[cur][path[0]];       // 返回起点
    return total;
}
```

- 时间复杂度：$O(n^2)$
- **不一定得到最优解**，但可给出近似解

### 策略二：最短链接策略
在整个图中选择**最短边**加入解集合，保证不产生回路和分枝。

```c
typedef struct { int u, v, w; } Edge;

int parent[MAXN];
int find(int x) { return parent[x] == x ? x : parent[x] = find(parent[x]); }

int TSP_ShortestLink(Edge edges[], int n, int e) {
    // edges 已按权值升序排列
    int degree[MAXN] = {0};          // 每个顶点的度数
    int sum = 0, cnt = 0;

    for (int i = 1; i <= n; i++) parent[i] = i;

    for (int i = 0; i < e && cnt < n; i++) {
        int u = edges[i].u, v = edges[i].v;
        // 不产生分枝（度数 < 2）且不产生回路
        if (degree[u] < 2 && degree[v] < 2 && find(u) != find(v)) {
            degree[u]++; degree[v]++;
            parent[find(u)] = find(v);
            sum += edges[i].w;
            cnt++;
        }
    }
    // 最后一条边连接两个度数为 1 的顶点形成回路
    return sum;
}
```

- 时间复杂度：$O(e \log e)$（排序）
- **不一定得到最优解**

## 7. Huffman 编码

### 问题描述
给定字符集及其出现频率，构造**最优的不等长二进制编码**（前缀编码）。

### 贪心策略
每次合并**权值最小**的两个字符（结点）。

### 构造步骤
1. 由 n 个权值构造 n 棵只有一个叶子结点的二叉树，得到集合 F
2. 在 F 中选根结点权值最小和次小的两棵作为左右子树构造新二叉树
3. 重复步骤 2，直到 F 只剩一棵二叉树（即哈夫曼树）
4. 左分支编码 '0'，右分支编码 '1'，从根到叶子的路径即为哈夫曼编码

### 时间复杂度
$$T(n) = O(n \log n)$$（使用小根堆）

### 伪代码
```c
#define MAXN 256
#define MAX_LEAF 100

typedef struct {
    int weight;                  // 权值
    int parent, lchild, rchild;  // 父结点、左右孩子下标
    char ch;                     // 字符（仅叶子结点有效）
    char code[MAXN];             // Huffman 编码（字符串形式）
} HuffmanNode;

// 在无父结点的结点中选两个权值最小的（*s1最小，*s2次小）
void selectMin(HuffmanNode tree[], int n, int *s1, int *s2) {
    int min1 = INT_MAX, min2 = INT_MAX;
    *s1 = *s2 = 0;
    for (int i = 1; i <= n; i++) {
        if (tree[i].parent == 0 && tree[i].weight < min1) {
            min2 = min1; *s2 = *s1;          // 原最小变为次小
            min1 = tree[i].weight; *s1 = i;  // 更新最小
        } else if (tree[i].parent == 0 && tree[i].weight < min2) {
            min2 = tree[i].weight; *s2 = i; // 更新次小
        }
    }
}

// 构造哈夫曼树
void HuffmanCoding(HuffmanNode tree[], int n) {
    int m = 2 * n - 1;                   // 哈夫曼树共有 2n-1 个结点
    for (int i = n + 1; i <= m; i++) {   // 合并 n-1 次，产生 n-1 个新结点
        int s1, s2;
        selectMin(tree, i - 1, &s1, &s2);  // 选两个最小权值的无父结点
        tree[s1].parent = i;             // 将s1、s2作为新结点i的左右孩子
        tree[s2].parent = i;
        tree[i].lchild = s1;
        tree[i].rchild = s2;
        tree[i].weight = tree[s1].weight + tree[s2].weight;  // 合并权值
    }
    // 生成每个叶子字符的哈夫曼编码（从叶子回溯到根）
    char tmp[MAXN];
    for (int i = 1; i <= n; i++) {
        int pos = MAXN - 1;
        tmp[--pos] = '\0';
        for (int c = i, f = tree[c].parent; f != 0; c = f, f = tree[f].parent) {
            if (tree[f].lchild == c) tmp[--pos] = '0';  // 左分支编码0
            else tmp[--pos] = '1';                      // 右分支编码1
        }
        strcpy(tree[i].code, tmp + pos);               // 保存编码结果
    }
}
```

### 正确性证明
- **贪心选择性质**：两个最小权值字符对应的结点是哈夫曼树中最深且为兄弟的结点（反证法）
- **最优子结构性质**：删除 x、y 后，将双亲 z 作为叶子结点的树仍是最优树（反证法）

## 8. Dijkstra 算法（单源最短路径）

### 问题描述
求从源点 v 到图中所有其他各顶点的最短路径长度（边权非负）。

### 贪心策略
选择从源点出发**当前最短路径所到达的顶点**（最近者优先），然后用该顶点修订到其他顶点的距离。

### 伪代码
```c
#define MAXN 1000
#define INF 0x3f3f3f3f

void Dijkstra(int G[MAXN][MAXN], int n, int s) {
    int dis[MAXN], visited[MAXN] = {0};

    // 初始化
    for (int i = 1; i <= n; i++)
        dis[i] = G[s][i];
    visited[s] = 1;

    for (int t = 1; t < n; t++) {
        // 从 V-S 中选 dis 最小的顶点 u
        int minDis = INF, u = -1;
        for (int i = 1; i <= n; i++)
            if (!visited[i] && dis[i] < minDis) {
                minDis = dis[i];
                u = i;
            }
        if (u == -1) break;
        visited[u] = 1;

        // 经 u 修订到其他顶点的距离
        for (int w = 1; w <= n; w++)
            if (!visited[w] && G[u][w] != INF)
                if (dis[u] + G[u][w] < dis[w])
                    dis[w] = dis[u] + G[u][w];
    }
}
```

### 时间复杂度
$$T(n) = O(n^2)$$

> 使用堆优化（优先队列）可降至 $O((n+e)\log n)$

## 9. 最小生成树问题

### 问题描述
给定一个带权无向连通图 G，求其最小生成树——包含所有 n 个顶点且边权和最小的连通子图（含 n-1 条边）。

### Prim 算法

**贪心策略**：选择连接 U 和 V-U 的**最短跨边**。

- 数据结构：数组 lowCost[]（最短跨边权值）、closest[]（对应顶点）
- 时间复杂度：$O(n^2)$

### Kruskal 算法

**贪心策略**：选择图中**最短边**合并两个不连通的分支（避环法）。

- 用并查集维护连通分支
- 时间复杂度：$O(e \log e)$（e 为边数）

### 伪代码
```c
#define MAXN 100
#define INF 0x3f3f3f3f

// ========== Prim 算法 ==========
int Prim(int G[MAXN][MAXN], int n) {
    int lowCost[MAXN], closest[MAXN];    // lowCost:到U的最短跨边权值, closest:对应顶点
    int visited[MAXN] = {0};             // visited标记已加入MST的顶点
    int sum = 0;

    visited[1] = 1;                      // 从顶点1开始构造
    for (int i = 2; i <= n; i++) {
        lowCost[i] = G[1][i];            // 初始化为顶点1到各顶点的距离
        closest[i] = 1;
    }

    for (int t = 1; t < n; t++) {        // 循环 n-1 次，加入 n-1 条边
        int minCost = INF, k = -1;
        for (int i = 2; i <= n; i++)     // 找V-U中lowCost最小的顶点
            if (!visited[i] && lowCost[i] < minCost) {
                minCost = lowCost[i];
                k = i;
            }
        if (k == -1) break;              // 图不连通
        visited[k] = 1;                  // 将k加入U
        sum += minCost;                  // 累加边权和
        for (int i = 2; i <= n; i++)     // 更新U到V-U中各顶点的最短跨边
            if (!visited[i] && G[k][i] < lowCost[i]) {
                lowCost[i] = G[k][i];
                closest[i] = k;          // 记录最短跨边的来源
            }
    }
    return sum;
}

// ========== Kruskal 算法 ==========
typedef struct { int u, v, w; } Edge;     // 边结构：u起点，v终点，w权值
Edge edges[MAXN * MAXN];
int parent[MAXN], rank[MAXN];             // 并查集：parent存储父结点，rank按秩合并

int find(int x) {                          // 查找x所在集合的根（路径压缩）
    return parent[x] == x ? x : parent[x] = find(parent[x]);
}

void unite(int x, int y) {                 // 合并x和y所在的两个集合（按秩合并）
    x = find(x); y = find(y);
    if (rank[x] < rank[y]) parent[x] = y;
    else { parent[y] = x; if (rank[x] == rank[y]) rank[x]++; }
}

int Kruskal(int n, int e) {
    // edges 已按权值升序排列
    for (int i = 1; i <= n; i++) parent[i] = i;   // 初始化并查集，每个顶点自成一集
    memset(rank, 0, sizeof(rank));

    int sum = 0, cnt = 0;
    for (int i = 0; i < e && cnt < n - 1; i++) {  // 遍历每条边，直到加入n-1条
        if (find(edges[i].u) != find(edges[i].v)) {  // u和v不在同一连通分量中
            unite(edges[i].u, edges[i].v);           // 合并两个分量（不产生回路）
            sum += edges[i].w;                        // 将边加入MST
            cnt++;                                    // 已选边数+1
        }
    }
    return sum;
}
```

# 五、回溯法（Backtracking）

## 0. 搜索算法概述

### 解空间
- **可能解**：所有可能的解向量构成问题的**解空间**
- **可行解**：满足约束条件的解向量
- **最优解**：使目标函数取得极值的可行解

### 解空间树
- **子集树**：从 n 个元素的集合中找出满足性质的子集 — $2^n$ 个叶结点
- **排列树**：确定 n 个元素满足某种性质的排列 — $n!$ 个叶结点

### DFS（深度优先搜索）
> "能进则进，不进则退"

### BFS（广度优先搜索）
> "由近及远，按层展开"

### 通用搜索框架
```
回溯算法 = 深度优先搜索 + 剪枝策略
分支限界算法 = 广度优先搜索 + 剪枝策略
```

---

## 1. 回溯法概述

### 设计思想
回溯法从根结点出发，按**深度优先**策略遍历解空间树，搜索满足约束条件的解。若当前结点肯定不包含可行解，就**回溯**尝试其他路径（剪枝）。

### 三种结点
- **扩展结点**：正在搜索其子结点的结点
- **活结点**：自身已搜索，子结点未全部搜索
- **死结点**：所有子结点已全部搜索

### 剪枝策略
1. **约束函数剪枝**：剪除不满足约束的子树（不可行解）
2. **限界函数剪枝**：剪除得不到最优解的子树

### 算法框架（递归回溯）
```c
void Backtrack(int t) {                 // t 为递归深度（当前层数）
    if (t == n) Output(x);              // 到达叶结点，找到一个解并输出
    else {
        for (int i = f(n,t); i <= g(n,t); i++) {  // 遍历当前层的所有可能取值
            x[t] = h(i);                // 记录当前层的选择
            if (Constraint(t) && Bound(t))        // 约束剪枝 + 限界剪枝
                Backtrack(t+1);         // 满足条件则深入下一层
            // 回溯：恢复状态（若x[t]被覆盖则无需显式清理）
        }
    }
}
```

### 子集树递归框架
```c
void Subset(int x[], int a[], int n, int t) {
    if (t == n) Output(x);                  // 所有元素已决策完毕，输出子集
    else {
        for (int i = 0; i <= 1; i++) {      // 两种选择：0不选 / 1选
            x[t] = i;                       // 决策第t个元素
            if (Constraint(t) && Bound(t))  // 剪枝判断
                Subset(x, a, n, t+1);       // 递归处理下一个元素
        }
    }
}
```

### 排列树递归框架
```c
void Perm(int x[], int n, int t) {
    if (t == n) Output(x);                      // 得到一个排列，输出
    else {
        for (int i = t; i < n; i++) {           // 枚举当前位置可放的元素
            swap(x[t], x[i]);                   // 将x[i]固定到当前位置t
            if (Constraint(t) && Bound(t))       // 剪枝判断
                Perm(x, n, t+1);                // 递归确定下一位置
            swap(x[t], x[i]);                   // 回溯：恢复交换前的状态
        }
    }
}
```

### 时空性能
- **时间**：最坏情况下子集树 $O(2^n)$，排列树 $O(n!)$。良好的剪枝可大幅提高效率。
- **空间**：只保存从根到当前扩展结点的路径，$O(h(n))$。

### 问题描述
给定无向连通图 G 和 m 种颜色，求所有不同的着色方案（相邻顶点不同色）。

### 约束函数

bool Same(int t) {                       // 判断顶点t与已着色顶点是否颜色冲突
    for (int i = 1; i <= n; i++)
        if (a[t][i] == 1 && x[t] == x[i])  // 存在相邻边且颜色相同

## 3. n 皇后问题

### 问题描述
在 $n \times n$ 棋盘上放 n 个皇后，使任意两个皇后不在同一行、同一列、同一斜线。

### 约束函数
```c
int x[MAXN];                       // x[t] 表示第 t 行皇后所在列号
int n, count = 0;                  // count 统计解的个数

bool Place(int t) {                              // 判断第t行的皇后是否与前面冲突
    for (int i = 1; i < t; i++)
        if (x[t] == x[i]                         // 同列冲突
            || abs(t-i) == abs(x[t]-x[i]))       // 斜线冲突：行差=列差
            return false;
    return true;
}
```

> **斜线冲突判断**：
> - 主对角线（↘）：行号 - 列号 = 常数
> - 副对角线（↗）：行号 + 列号 = 常数

### 回溯算法
```c
void Queen(int t) {
    if (t > n) {                       // 所有行都已放置，得到一个解
        count++;
        Output(x);                     // 输出当前解（皇后列号序列）
    } else {
        for (int i = 1; i <= n; i++) { // 枚举第 t 行皇后可放的列
            x[t] = i;
            if (Place(t))              // 约束剪枝：与已放皇后不冲突
                Queen(t + 1);          // 递归放置下一行
            // 回溯：x[t] 会被下一轮覆盖，无需显式清理
        }
    }
}

// 调用：Queen(1);  从第 1 行开始放置
```

### 时间复杂度
最坏情况：$O(n!)$（利用排列树优化后）

## 4. 0/1 背包问题（回溯法）

### 问题描述
同 DP 章节的 0/1 背包问题，这里用回溯法在解空间树中搜索最优解，通过剪枝提高效率。

### 剪枝策略
- **左剪枝（约束函数）**：$cw + w[t] > C$ 时剪枝
- **右剪枝（限界函数）**：计算上界 $ub$，若 $cv + ub \leq bestv$ 则剪枝

### 上界计算
```c
int Bound(int i) {                      // 贪心法计算上界（剩余物品的最大价值估计）
    int r = C - cw;                     // 背包剩余容量
    int ub = cv;                        // 当前已选物品的总价值
    while (i <= n && w[i] <= r) {       // 能完整装入的物品全部装入
        r -= w[i]; ub += v[i]; i++;
    }
    if (i <= n && r != 0)               // 最后一个物品按比例部分装入（上界放宽）
        ub += v[i] * r / w[i];          // 单位重量价值 × 剩余容量
    return ub;                          // 返回乐观估计的最大价值
}
```

### 回溯算法
```c
void Knapsack(int t) {
    if (t > n) {                                 // 到达叶结点，得到一个完整解
        if (cv > bestv) {                        // 当前解优于已知最优解
            bestv = cv;                          // 更新最优值
            for (int i = 1; i <= n; i++) bestx[i] = x[i];  // 记录最优解向量
        }
    } else {
        x[t] = 1;                                // 左子树：选取物品t
        if (cw + w[t] <= C) {                    // 约束剪枝：不超过容量
            cw += w[t]; cv += v[t];              // 更新当前重量和价值
            Knapsack(t+1);                       // 递归处理下一物品
            cw -= w[t]; cv -= v[t];              // 回溯：撤销选择
        }
        x[t] = 0;                                // 右子树：不选取物品t
        if (Bound(t+1) > bestv)                  // 限界剪枝：上界有希望才搜索
            Knapsack(t+1);
    }
}
```

### 时间复杂度
最坏情况：$O(n \cdot 2^n)$

# 六、分支限界法（Branch and Bound）

## 1. 分支限界法概述

### 设计思想
采用**广度优先**或**最小耗费优先**的策略搜索解空间树。用限界函数计算目标函数值，选择最有利的子结点作为扩展结点。

### 求解步骤
1. 确定解的形式，定义解空间
2. 确定**限界函数**，计算目标函数的界 $[down, up]$
3. 按广度优先搜索，扩展结点的所有孩子结点，根据限界函数丢弃超出界的结点
4. 从活结点表中选取使目标函数取极值的结点作为当前扩展结点
5. 重复步骤 3、4，直到找到最优解

### 关键问题
1. **限界函数**：计算简单、保证最优解在搜索空间、早期丢弃超出界的结点
   - 求最大值：设计上界 $ub$，父结点 $ub \geq$ 子结点 $ub$
   - 求最小值：设计下界 $lb$，父结点 $lb \leq$ 子结点 $lb$
2. **活结点表存储结构**：优先队列（常用）或数组
3. **确定最优解分量**：保存从根到该结点的路径，或保存双亲指针

### 活结点扩展方式
- **队列式（FIFO）**：先进先出
- **优先队列式**：按优先级（目标函数值）选择
  - 求最大值：用**大根堆**（优先级为上界 $ub$）
  - 求最小值：用**小根堆**（优先级为下界 $lb$）

### 分支限界法与回溯法的区别
| 对比维度 | 回溯法 | 分支限界法 |
|---------|-------|-----------|
| 搜索方式 | 深度优先 | 广度优先 / 最小耗费优先 |
| 结点存储 | 栈 | 队列 / 优先队列 |
| 结点扩展 | 所有子结点遍历后才出栈 | 每个结点只有一次成为活结点 |
| 求解目标 | 所有解 / 一个解 / 最优解 | 一个解 / 最优解 |
| 适用场景 | 约束满足问题 | 最优化问题 |

## 2. 0/1 背包问题（分支限界法）

### 问题描述
同 DP、回溯法章节的 0/1 背包问题，这里用分支限界法通过优先队列搜索解空间树，利用上界剪枝。

### 限界函数（上界）
利用贪心法计算当前分支能获得的最大价值上界：
```c
void bound(NodeType &e) {                 // 计算当前结点的价值上界
    int i = e.i + 1;                      // 从剩余第一个物品开始
    int sumw = e.w;                       // 当前已用重量
    double sumv = e.v;                    // 当前已得价值
    while ((sumw + w[i] <= C) && i <= n) { // 能完整装入的物品全部装入
        sumw += w[i];
        sumv += v[i];
        i++;
    }
    if (i <= n)                           // 最后一个物品部分装入（贪心放宽）
        e.ub = sumv + (C - sumw) * v[i] / w[i];   // 按单位价值比例装入
    else
        e.ub = sumv;                      // 所有物品都能装下
}
```

### 伪代码（优先队列式）
```c
#define MAXN 100

typedef struct {
    int i;                     // 当前处理到第 i 个物品
    int cw, cv;                // 当前重量、价值
    double ub;                 // 上界
    int x[MAXN];               // 当前解向量
} Node;

struct cmp {                   // 大根堆比较
    bool operator()(Node a, Node b) {
        return a.ub < b.ub;
    }
};

void bound(Node &e, int w[], int v[], int n, int C) {
    int i = e.i + 1;                           // 从剩余第一个物品开始
    int sumw = e.cw;
    double sumv = e.cv;
    while (i <= n && sumw + w[i] <= C) {       // 贪心地完整装入能装下的物品
        sumw += w[i];
        sumv += v[i];
        i++;
    }
    if (i <= n)                                // 最后一件按比例装入（放宽上界）
        e.ub = sumv + (C - sumw) * (double)v[i] / w[i];
    else
        e.ub = sumv;
}

int Knapsack_BB(int w[], int v[], int n, int C) {
    priority_queue<Node, vector<Node>, cmp> q;  // 大根堆，按ub降序

    Node s;                                      // 初始化根结点
    s.i = 0;  s.cw = 0;  s.cv = 0;
    memset(s.x, 0, sizeof(s.x));
    bound(s, w, v, n, C);
    q.push(s);

    int bestv = 0;                               // 当前最优价值
    int bestx[MAXN];

    while (!q.empty()) {
        Node u = q.top(); q.pop();               // 取出上界最大的结点

        if (u.i == n) {                          // 到达叶结点（所有物品已决策）
            if (u.cv > bestv) {                  // 更新最优解
                bestv = u.cv;
                memcpy(bestx, u.x, sizeof(bestx));
            }
            continue;
        }
        // 左分支：选取物品 u.i+1
        if (u.cw + w[u.i + 1] <= C) {            // 可行性剪枝
            Node lchild = u;
            lchild.i = u.i + 1;
            lchild.cw += w[lchild.i];
            lchild.cv += v[lchild.i];
            lchild.x[lchild.i] = 1;
            bound(lchild, w, v, n, C);
            if (lchild.ub > bestv) q.push(lchild); // 上界有希望才入队
        }
        // 右分支：不选取物品 u.i+1
        Node rchild = u;
        rchild.i = u.i + 1;
        rchild.x[rchild.i] = 0;
        bound(rchild, w, v, n, C);
        if (rchild.ub > bestv) q.push(rchild);     // 上界有希望才入队
    }
    return bestv;
}
```

### 时间复杂度
最坏情况：$O(n \cdot 2^n)$

## 3. TSP 问题（分支限界法）

### 问题描述
同 DP 章节的 TSP 问题，这里用分支限界法通过优先队列搜索解空间树，利用下界剪枝寻找最优解。

### 下界计算
每个城市有两条邻接边（一条进、一条出），将每行最小两个元素相加除以 2（取整）：
$$lb = \frac{\sum(\text{每行最小的两个元素之和})}{2}$$

### 上界计算
用贪心法（最近邻点策略）估算一个可行解作为上界。

### 限界函数（部分解）
对于已确定路径 $U = (r_1, r_2, ..., r_k)$：
- 已确定路径的长度
- 剩余顶点按每行最小边估算

### 算法步骤
1. 计算 $lb$，根结点入表 PT
2. 循环直到某叶子结点的 $lb$ 在 PT 中最小：
   - 取 PT 中 $lb$ 最小的结点
   - 扩展其所有孩子结点，计算 $lb$，若 $lb \leq up$ 则入队
   - 若叶子结点 $lb$ 在 PT 中最小，则得到最优解

### 伪代码
```c
#define MAXN 100
#define INF 0x3f3f3f3f

typedef struct {
    int path[MAXN];          // 已确定的顶点路径
    int k;                   // 已确定路径中的顶点数
    int lb;                  // 当前路径的下界
    int visited[MAXN];       // 顶点是否已访问（1表示已访问）
} Node;

// 计算当前结点的下界
int getLB(int G[MAXN][MAXN], int n, Node u) {
    int lb = 0;
    // 已确定路径的累加长度
    for (int i = 0; i < u.k - 1; i++)
        lb += G[u.path[i]][u.path[i + 1]];
    // 对每个未访问顶点，加上其最小两条出边之和的一半（下界估计）
    for (int i = 1; i <= n; i++) {
        if (u.visited[i]) continue;
        int min1 = INF, min2 = INF;        // 找该行最小和次小边权
        for (int j = 1; j <= n; j++) {
            if (G[i][j] < min1) { min2 = min1; min1 = G[i][j]; }
            else if (G[i][j] < min2) min2 = G[i][j];
        }
        lb += (min1 + min2) / 2;
    }
    return lb;
}

// 优先队列分支限界法求解TSP
int TSP_BB(int G[MAXN][MAXN], int n) {
    priority_queue<Node> q;          // 小根堆，按 lb 升序排列
    Node s;
    memset(s.visited, 0, sizeof(s.visited));
    s.path[0] = 1;  s.k = 1;  s.visited[1] = 1;   // 从城市1出发
    s.lb = getLB(G, n, s);
    q.push(s);

    int bestv = INF;                 // 上界（可用贪心法初始化）
    int bestPath[MAXN];

    while (!q.empty()) {
        Node u = q.top(); q.pop();   // 取出lb最小的结点扩展
        if (u.k == n) {              // 已访问所有顶点，到达叶结点
            int total = 0;
            for (int i = 1; i < n; i++)
                total += G[u.path[i - 1]][u.path[i]];
            total += G[u.path[n - 1]][u.path[0]];   // 回到起点
            if (total < bestv) {                    // 更新最优解
                bestv = total;
                memcpy(bestPath, u.path, sizeof(u.path));
            }
            continue;
        }
        // 扩展当前结点的所有未访问孩子
        for (int v = 2; v <= n; v++) {
            if (!u.visited[v]) {
                Node child = u;
                child.path[child.k] = v;            // 加入新城市v
                child.k++;
                child.visited[v] = 1;
                child.lb = getLB(G, n, child);
                if (child.lb < bestv)               // 下界剪枝
                    q.push(child);
            }
        }
    }
    return bestv;
}
```

### 时间复杂度
最坏情况：$O(n \cdot n!)$
