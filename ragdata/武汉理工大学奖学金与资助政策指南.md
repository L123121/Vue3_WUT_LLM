# 武汉理工大学奖学金与资助政策指南

> 汇总国家、学校两级奖助学金体系，以及勤工助学、助学贷款等资助渠道，帮助家庭经济困难学生了解申请路径。

## 一、奖学金体系概览

| 奖学金名称 | 金额 | 覆盖比例 | 评选时间 |
|------|------|:---:|------|
| 国家奖学金 | 8000 元/年 | 约 2% | 每年 9-10 月 |
| 国家励志奖学金 | 5000 元/年 | 约 4% | 每年 9-10 月 |
| 校长奖学金 | 10000 元/年 | 全校 10 名 | 每年 12 月 |
| 校级一等奖学金 | 2000 元/年 | 约 5% | 每学年末 |
| 校级二等奖学金 | 1200 元/年 | 约 10% | 每学年末 |
| 校级三等奖学金 | 600 元/年 | 约 15% | 每学年末 |

## 二、申请条件

- **国家奖学金**：二年级及以上本科生，学年综合测评排名前 10%，无挂科记录，有突出成绩或科研成果者优先。
- **国家励志奖学金**：二年级及以上本科生，家庭经济困难认定通过，综合测评排名前 30%。
- **校长奖学金**：在学术科研、学科竞赛、创新创业、志愿服务等方面有标志性成果，综合表现特别突出的学生。
- **校级奖学金**：学年无挂科，德育考核合格，按综合测评成绩分档评定。

## 三、助学金与资助渠道

1. **国家助学金**：分三档——一等 4500 元/年、二等 3300 元/年、三等 2000 元/年，家庭经济困难学生可申请。
2. **生源地助学贷款**：每年 8-9 月向户籍所在地教育局申请，本科最高 16000 元/年，在校期间利息由国家承担。
3. **勤工助学**：校内岗位约 2000 个，时薪 18-25 元，每月工作不超过 40 小时，可通过学工系统在线申请。
4. **绿色通道**：新生报到时可凭录取通知书申请缓缴学费，先入学再办理贷款。

## 四、家庭经济困难认定

认定工作每学年秋季学期开展，流程如下：

```
学生申请 → 班级评议 → 学院审核 → 学校认定 → 结果公示（5 个工作日）
```

所需材料：申请表、家庭经济情况证明、户口本复印件等，具体以学院通知为准。

## 五、常见问题

| 问题 | 解答 |
|------|------|
| 奖学金会每年重复评定吗？ | 会，每学年评定一次，可重复获得 |
| 挂科了还能申请奖学金吗？ | 当学年挂科一般不能参评国家奖学金与校级奖学金 |
| 助学金与奖学金冲突吗？ | 不冲突，可同时申请 |
| 奖学金发放时间 | 评选公示无异议后一个月内发放至学生银行卡 |
