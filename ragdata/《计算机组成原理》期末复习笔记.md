## 1.1 数据表示与存储

### 整数补码表示（必考）

**核心规则**：
- **正数**：补码 = 原码（不变）
- **负数**：补码 = 符号位不变 + 数值位取反 + 末位加1
- **补码→原码**：同样操作（取反加1）

> ⚠️ 易错：负数补码不是"符号位1+数值绝对值"，必须"取反加1"

**【解题模板】负数补码计算**

**题目**：12位有符号整数 x = -36，求补码

**步骤**：
1. 36的二进制 = 100100₂
2. 12位原码形式：0,0000100100（最高位0为符号位）
3. 负数补码：最高位改为1，数值位取反加1
   - 取反：1,1111011011
   - 加1：1,1111011100
4. 结果：`111111011100₂`

**【解题模板】补码求十进制值**

**题目**：signed char a = 0xA3，unsigned char b = 0xA3，求十进制值

**步骤**：
1. **判断数据类型**：
   - b是无符号数 → 直接计算
   - a是有符号数 → 看最高位
2. **b（无符号）**：0xA3 = 128+32+2+1 = **163**
3. **a（有符号）**：最高位1 → 负数（补码）
   - 方法1：取反加1 → 原码 = 1,00110101 → **-53**
   - 方法2（快速公式）：a = 0xA3 - 256 = **-53**

### 数值范围公式

| 类型 | 位数 | 范围 | 公式 |
|------|------|------|------|
| 有符号 | n位 | -2^(n-1) ~ 2^(n-1)-1 | 负数比正数多1个 |
| 无符号 | n位 | 0 ~ 2^n - 1 | 全是数值位 |

### 十六进制→十进制转换（必考格式）

> ⚠️ **考试格式**：答案需写为 **0xA3₁₆**（下标标注进制），负数需先转补码再算值

**步骤**：
1. 无符号数：直接按权展开
2. 有符号数：先看最高位，若为1则按补码→原码→十进制值
3. 书写格式：`0x??₁₆` 或明确标注"十六进制数"

**【解题模板】补码求十进制值**

**题目**：signed char a = 0xA3，unsigned char b = 0xA3，求十进制值

### 小数的表示方法

- 定点小数：小数点固定在最高位之后（即纯小数）
- 定点整数：小数点固定在最低位之后

### 大端与小端模式（高频）

- **小端模式**：低字节存低地址（RISC-V、x86使用）
- **大端模式**：高字节存低地址

**【解题模板】小端模式读取**

**题目**：&x=0x202，存储器地址0x202~0x205存储：F2,FE,FF,FF。求x值（int，有符号）

**步骤**：
1. 小端模式：低地址存低字节
2. 拼接：从高地址向低地址拼接 → x = 0xFFFFFEF2
3. 最高位1 → 负数（补码）
4. 取反加1 → 原码 = 0x0000010E → **-270**

> 【易错】拼接时：高地址的字节是高位！

## 1.2 IEEE 754 浮点数（必考）

### 32位浮点数格式

```
[数符S:1位] [阶码E:8位] [尾数M:23位]
```

**公式**：V = (-1)^S × 1.M × 2^(E-127)  🔴 必考

**字段含义**：
- S = 0正数，S = 1负数
- E = 实际阶码 + 127（移码表示）
- M = 小数点后的位数（小数点前隐含一个1）

### 浮点数的存储方法

- 按 **1位S + 8位E + 23位M** 的顺序依次存放
- E用移码（偏置127），全0和全1有特殊含义
- 单精度float占4字节，双精度double占8字节

**【解题模板】十进制转IEEE 754**

**题目**：float y = -96.75，求十六进制表示

**步骤**：
1. |y| = 96.75 = 01100000.11₂（整数96=0x60，小数0.75=0.11₂）
2. 规格化：1.10000011 × 2^6
3. 阶码E = 6 + 127 = 133 = **10000101₂**
4. 尾数M = 10000011000000000000000（小数点后补0到23位）
5. 数符S = 1
6. 拼合：1 10000101 10000011000000000000000
7. 4位分组：1100/0010/1100/0001/1000/0000/0000/0000
8. 结果：**0xC2C18000**

> 【易错】尾数在后面补0，阶码在前面补0（补0不改变数值）

**【解题模板】IEEE 754转十进制**

**步骤**：
1. 分离S、E、M（按1/8/23位划分）
2. 实际阶码 = E - 127
3. 尾数值 = 1.M（前面隐含一个1）
4. 计算 V = (-1)^S × 1.M × 2^(实际阶码)

## 1.3 定点数加减运算及溢出判断（必考）

### 补码加减法规则

- **加法**：[A+B]补 = [A]补 + [B]补 (mod 2^(n+1))
- **减法**：[A-B]补 = [A]补 + [-B]补
- **[-B]补**：[B]补连同符号位全部取反 + 1

> ⚠️ 易错：[-B]补是[B]补**连同符号位**全部取反再加1，不是只取反数值位！

**【解题模板】补码加减法运算**

**题目**：x = 19/32 = 0.10011, y = -19/32 = -0.10011，求 x-y（双符号位补码）

**步骤**：
1. 求补码：
   - x补 = **00.10011**（正数不变）
   - y补 = **11.01101**（负数：取反加1）
   - -y补 = **00.10011**（y补连同符号位取反加1）
2. 计算：
   ```
     00.10011   x补
   + 00.10011   -y补
   ──────────
     01.00110
   ```
3. 判断溢出：双符号位01 → **正溢出**（超出可表示范围）

### 溢出判断（必考）

**双符号位溢出判断**：

| 双符号位 | 含义 |
|----------|------|
| 00 | 正数，不溢出 |
| 01 | **正溢出** |
| 10 | **负溢出** |
| 11 | 负数，不溢出 |

> ⚠️ 易错：双符号位01=正溢出，10=负溢出，不要记反！

**有符号数溢出判断（公式法）**：

**公式**：OF = C_(n-1) ⊕ C_n  🔴 必考

- C_(n-1)：次高位进位（数值最高位向符号位的进位）
- C_n：最高位进位（符号位向更高位的进位）

| 情况 | C_(n-1) | C_n | OF | 说明 |
|------|---------|-----|-----|------|
| 正+正得负 | 1 | 0 | **1** | 溢出 |
| 负+负得正 | 0 | 1 | **1** | 溢出 |
| 正+负 | - | - | **0** | 不溢出 |

> 【易错】两个正数相加得负数，或两个负数相加得正数，必定溢出！

**无符号数溢出判断**：

**公式**：Cout = C_n（最高位有进位则溢出）

> 【易错】有符号和无符号溢出判断方法不同！

## 1.4 乘除法运算

> **考点说明**：要求掌握**两个**除法方法。

### 定点乘法

**原码一位乘法**：

**规则**：
1. 符号位：两符号异或（XOR）
2. 数值部分：绝对值相乘，部分积右移法

**运算过程**：
```
部分积初值 = 0
循环n次（n为乘数位数）：
  若乘数最低位=1：部分积 = 部分积 + |被乘数|
  若乘数最低位=0：部分积 = 部分积 + 0
  部分积右移1位（逻辑右移，高位补0）
  乘数右移1位
```
- 每次判断乘数的最低位（LSB）
- 部分积右移时，被移出的最低位可用于保存商

**操作**：
- 乘数位=1：部分积+被乘数，右移1位
- 乘数位=0：部分积+0，右移1位

**二位乘法**：

每次处理2位乘数：
- 00：加0，右移2位
- 01：加1倍，右移2位
- 10：加2倍，右移2位
- 11：减1倍，右移2位，向高位进1

### 定点除法（要求掌握两个方法）

**方法一：加减交替法**

```
R = R - y;  // 第一次试减
循环n次：
  if R ≥ 0: 上商1, R左移, R = R - y
  else:     上商0, R左移, R = R + y
```

**方法二：原码恢复余数法**

（与加减交替法类似，但每次试减不满足时需恢复余数，再左移。加减交替法是其改进版，将恢复余数与下一步的左移合并为+R。）

## 2.1 C→汇编→机器码转换 & 汇编填空（必考）

> 解题关键：**追踪寄存器值的变化**，建立寄存器-变量对应表

### C语句→指令数（理解）

| C语句 | 需要指令数 | 说明 |
|-------|-----------|------|
| `c = a + b` | 4条 | 2条load（读a,b）+ 1条add（计算）+ 1条store（写c） |
| `if (a > b)` | 2~3条 | load值 + bge/blt比较跳转 |

> 【考点】一道经典考题：理解C语言的一条赋值语句在CPU中需要多条指令完成（load→运算→store）

### 【解题模板】汇编填空

**技巧**：
1. 识别指令类型 → 推断操作数位置
2. 追踪寄存器变化 → 建立寄存器-变量对应表
3. 根据上下文推断跳转地址

**例题**：
```assembly
800007a: add a4, __1__, __2__    # a += i → a4=a4+a5
800007c: addi a5, a5, __3__      # i++ → 加1
800007e: bne a5, __4__, 800007a  # i≠b → a3是b的值
```
**答案**：1=a4, 2=a5, 3=1, 4=a3

### 机器码→汇编的反向推理

给定机器码（十六进制）推断：
1. 转二进制
2. 按指令格式分割字段（opcode→类型→各字段）
3. 根据opcode确定指令类型和具体指令
4. 提取rs1、rs2、rd、imm等字段
5. 还原为汇编指令

## 2.3 RISC-V寄存器与核心指令（必背）

### RISC-V寄存器

| 寄存器 | ABI名 | 用途 | 调用约定 |
|--------|-------|------|----------|
| x0 | zero | 永远为0（不可修改） | - |
| x1 | ra | 返回地址 | 被调用者保存 |
| x2 | sp | 栈指针 | 被调用者保存 |
| x3 | gp | 全局指针 | — |
| x10-x11 | a0-a1 | 参数/返回值 | 调用者保存 |
| x12-x17 | a2-a7 | 函数参数 | 调用者保存 |
| x5-x7 | t0-t2 | 临时寄存器 | 调用者保存 |
| x8-x9, x18-x27 | s0-s11 | 保存寄存器 | 被调用者保存 |

**参数传递**：从a0开始依次存放，最多9个（a0~a8），返回值放a0

> 【速记】a0~a8 对应 x10~x18（共9个参数寄存器），即 aN = x(N+10)

### 数据传送指令

| 指令 | 格式 | 功能 |
|------|------|------|
| lw | lw rd, imm(rs1) | mem[rs1+imm] → rd（读4字节） |
| lh/lhu | lh rd, imm(rs1) | 读2字节（有符号/无符号扩展） |
| lb/lbu | lb rd, imm(rs1) | 读1字节（有符号/无符号扩展） |
| sw | sw rs2, imm(rs1) | rs2 → mem[rs1+imm]（写4字节） |
| sh/sb | sh rs2, imm(rs1) | 写2/1字节 |

> 【易错】只有读指令需区分有符号/无符号，写指令不区分

### 符号扩展与零扩展

| 指令 | 读取宽度 | 扩展方式 | 示例（读取0xFFD0） |
|------|---------|---------|-------------------|
| lb | 1字节 | **符号扩展**（高位补符号位） | 0xFFD0 → 0xFFFFFFD0（负数） |
| lbu | 1字节 | **零扩展**（高位补0） | 0xFFD0 → 0x000000D0 |
| lh | 2字节 | **符号扩展**（高位补符号位） | 0xFFD0 → 0xFFFFFFD0（负数） |
| lhu | 2字节 | **零扩展**（高位补0） | 0xFFD0 → 0x0000FFD0 |
| lw | 4字节 | 不需扩展（直接读满32位） | — |

> ⚠️ **易错**：lb/lh是有符号读取，读取后会做**符号扩展**；lbu/lhu是无符号读取，高位补0。用错指令会导致数值错误！

### 算术运算指令

| 指令 | 格式 | 功能 |
|------|------|------|
| add | add rd, rs1, rs2 | rd = rs1 + rs2 |
| addi | addi rd, rs, imm | rd = rs + imm（12位立即数，范围-2048~2047） |
| sub | sub rd, rs1, rs2 | rd = rs1 - rs2 |
| or | or rd, rs1, rs2 | rd = rs1 \| rs2（按位或） |
| and | and rd, rs1, rs2 | rd = rs1 & rs2（按位与） |
| srai | srai rd, rs, shamt | 算术右移（高位补符号位） |
| srli | srli rd, rs, shamt | 逻辑右移（高位补0） |
| lui | lui rd, imm | rd = imm << 12（高20位） |

> **lui + addi组合**：构造32位地址的标准方法（lui装高20位，addi补低12位）

| 指令 | 格式 | 功能 | 说明 |
|------|------|------|------|
| li | li rd, imm | rd = imm | **伪指令**，小立即数→addi，大立即数→lui+addi |
| mv | mv rd, rs | rd = rs | **伪指令**，实际为 addi rd, rs, 0 |
| la | la rd, symbol | rd = symbol(地址) | **伪指令**，加载标签/符号地址到寄存器 |

### 分支跳转指令

| 指令 | 格式 | 功能 |
|------|------|------|
| beq | beq rs1, rs2, label | rs1=rs2 则跳转 |
| bne | bne rs1, rs2, label | rs1≠rs2 则跳转 |
| blt | blt rs1, rs2, label | rs1<rs2 则跳转（**有符号**比较） |
| bge | bge rs1, rs2, label | rs1≥rs2 则跳转（**有符号**比较） |
| bltu/bgeu | - | 无符号比较版本 |
| jal | jal label | ra=PC+4, PC=label |
| jalr | jalr rd, rs1, imm | rd=PC+4, PC=rs1+imm |
| ret | ret | PC=ra（函数返回）**伪指令**，实际为 jalr x0, x1, 0 |

> 【易错】blt/bge是有符号比较，bltu/bgeu是无符号比较！

### RISC-V指令格式速查

| 类型 | 指令示例 | opcode(6-0) |
|------|----------|-------------|
| **R型** | add, sub, and, or, sll | 0110011 |
| **I型** | addi, lw, lb, jalr | 0010011(addi) / 0000011(lw/lb) / 1100111(jalr) |
| **S型** | sw, sb, sh | 0100011 |
| **B型** | beq, bne, blt, bge | 1100011 |
| **U型** | lui | 0110111 |
| **J型** | jal | 1101111 |

**各类型格式图**：

| 类型 | 格式 |
|------|------|
| **R型** | `funct7(7)` + `rs2(5)` + `rs1(5)` + `funct3(3)` + `rd(5)` + `opcode(7)` |
| **I型** | `imm[11:0](12)` + `rs1(5)` + `funct3(3)` + `rd(5)` + `opcode(7)` |
| **S型** | `imm[11:5](7)` + `rs2(5)` + `rs1(5)` + `funct3(3)` + `imm[4:0](5)` + `opcode(7)` |

**移位指令的shamt字段**：
- srai/srli/sll等使用I型格式
- imm[11:7]用作**移位量shamt(5位)**，imm[6:0]编码到funct7中

**funct7的作用**（R型指令中区分不同指令）：
- `add`：funct7 = 0000000, funct3 = 000
- `sub`：funct7 = 0100000, funct3 = 000
- `or`：funct7 = 0000000, funct3 = 110
- `and`：funct7 = 0000000, funct3 = 111

### 【解题模板】bge机器码计算

**题目**：bge a5, a3, 0x800008a，求机器码

**步骤**：
1. 偏移值 = 0x800008a - 0x8000076 = 0x14 = 20
2. imm = 20 / 2 = **10**（地址对齐，偏移值/2存入机器码）
3. rs1 = a5 = x15 = **01111₂**
4. rs2 = a3 = x13 = **01101₂**
5. imm字段编码：
   - imm[12|10:5] = 0000000（imm=10，二进制0000001010）
   - imm[4:1|11] = 10100
6. 拼合：0000000 01101 01111 101 10100 1100011
7. 转十六进制：**0x00d7da63**

## 3.1 存储器基础结构（必考）

### 存储器三种总线

| 总线 | 方向 | 功能 |
|------|------|------|
| 地址线(A) | CPU→存储器(单向) | 传送存储单元地址 |
| 数据线(D) | CPU↔存储器(双向) | 传送读出/写入数据 |
| 控制线(CS,WR) | CPU→存储器(单向) | 控制读/写操作 |

### 控制信号含义

- **CS=0**：芯片选中（工作）
- **CS=1**：芯片未选中
- **WR=1**：读操作
- **WR=0**：写操作

> 【易错】CS=0是选中，不是CS=1！

### 存储器容量计算（必考）

**公式**：容量 = 2^n × m bits  🔴 必考

- n根地址线 → 2^n个存储单元
- m根数据线 → 每单元m位

> ⚠️ 易错：n根地址线→2^n个单元，不是n个单元！

**例题**：13根地址线，16根数据线
- 容量 = 2^13 × 16 = 8K × 16bit = 8K × 2B = **16KB**

### 译码器功能

**功能**：n个输入端 → 2^n个输出端

**规则**：输入=k时，仅输出端Yk产生信号

**两种译码驱动方式**：

| 方式 | 字线数 | 特点 |
|------|--------|------|
| 线选法 | 2^(m+n) | 简单但线多 |
| 重合法 | 2^m + 2^n | 复杂但线少 |

### 存储器扩展

**位扩展**（增加存储字长）：多个存储器**并联**，共用地址线
- 例：2片 1K×4位 → 1K×8位

**字扩展**（增加存储单元数）：多个存储器**串联**，高位地址线接CS
- 例：2片 1K×8位 → 2K×8位（A10接CS）

**字位混合扩展**：例：8片 1K×4位 → 4K×8位
1. 先位扩展：每2片并联成1K×8位（共4组）
2. 再字扩展：高2位A11A10通过译码器片选4组

## 4.1 Cache与主存映射机制（必考）

### 主存与Cache差异

| | Cache | 主存 |
|---|-------|------|
| 材料 | SRAM（不需刷新） | DRAM（需定期刷新） |
| 速度 | 快（几ns） | 慢（几十ns） |
| 容量 | 小（几MB） | 大（几GB） |

### 局部性原理

- **时间局部性**：刚访问的数据很可能再访问（循环变量）
- **空间局部性**：访问某地址后，邻近地址很可能被访问（数组）

### CPU访问主存的过程

**流程**：
1. CPU给出主存地址
2. **先访问Cache**：根据地址找到对应块/组
3. **比较标记值**：若相等 → **命中**（Cache命中，直接返回数据）
4. **未命中**：从主存读取数据块，加载到Cache，再返回数据给CPU

> ⚠️ **易错**：Cache访问是先找块/组，再比较标记值；不是直接比较所有Cache块！

### Cache查找判断

**直接映射查找**：
1. 从地址提取Cache块地址 → 定位到Cache块
2. 从地址提取标记值
3. 读取Cache块中存储的标记值
4. 比较：相等→**命中**，不等→**未命中**

**组相联查找**：
1. 从地址提取组地址 → 定位到组
2. 从地址提取标记值
3. 逐一比较组中各Cache块的标记值

### 地址位数计算公式

- 主存地址位数 L = log₂(主存容量)  🔴 必考
- 块内地址位数 b = log₂(块大小)
- Cache块地址位数 c = log₂(Cache块数)
- 标记位数 = L - b - c

> ⚠️ 易错：组相联中组地址位数 = log₂(组数)，不是 log₂(Cache块数)

### 三种映射方式地址格式

| 映射方式 | 地址格式 | 说明 |
|----------|----------|------|
| **直接映射** | [标记][Cache块地址][块内地址] | 主存块号 mod Cache块数 |
| **全相联映射** | [标记][块内地址] | 标记=主存块号 |
| **N路组相联** | [标记][组地址][块内地址] | 组数 = Cache块数/N |

### 【解题模板】Cache地址格式计算

**题目**：主存4MB，Cache 8KB，块大小512B，按字节寻址

**直接映射**：
1. 主存地址 L = log₂4MB = **22位**
2. 块内地址 b = log₂512B = **9位**
3. Cache块数 = 8KB/512B = 16块 → c = log₂16 = **4位**
4. 标记位数 = 22 - 9 - 4 = **9位**
5. 地址格式：`[标记9位][Cache块地址4位][块内地址9位]`

**2路组相联**：
1. L = 22位，b = 9位
2. Cache块数 = 16块，组数 = 16/2 = 8组
3. 组地址位数 = log₂8 = **3位**
4. 标记位数 = 22 - 9 - 3 = **10位**
5. 地址格式：`[标记10位][组地址3位][块内地址9位]`

### 【解题模板】地址映射计算

**直接映射**：主存地址0x3ABCDE映射到哪个Cache块？
1. 地址转二进制：0x3ABCDE = 11 1010 1011 1100 1101 1110
2. 按9|4|9划分：111010101 | 1110 | 011011110
3. Cache块号 = 1110₂ = **14**
4. 标记值 = 111010101₂ = **469**

**2路组相联**：
1. 按10|3|9划分：1110101011 | 110 | 011011110
2. 组号 = 110₂ = **6**
3. 标记值 = 1110101011₂ = **939**

### LRU替换算法

**规则**：淘汰最近最少使用的块

**计数器操作**：
- 命中：被访问块计数置0，比它低的加1
- 未命中未满：新块计数置0，其余加1
- 未命中已满：淘汰计数最大的，新块置0，其余加1

| 100 | srl（逻辑右移） |
| 101 | sra（算术右移） |
| 110 | sub（减） |
| 111 | sll（左移） |

**PC程序计数器**：
- PC_out：读当前PC值
- PC_in：写入新PC值
- 顺序执行时：PC = PC + 4

**寄存器堆（Regfile）**：
- **读操作**：可同时读2个寄存器（双端口），不需要时钟触发（组合逻辑）
- **写操作**：每次只能写1个寄存器，需要时钟上升沿触发，WR=1时才写入

> 【易错】读操作不需要时钟，写操作需要时钟！

## 5.2 RISC-V CPU结构设计

> **考点说明**：分析RISC-V指令在CPU电路中是如何运行的。去掉电路的部分模块，要求学生**补充完整电路**（或补全空缺的连线）。针对CPU数据通路结构，分析给定指令的执行过程及数据流向（可能涉及补充部分电路元件）。
>
> 📌 **考试要求**：add、sub、or、and、lw、sw、beq、addi 各条指令在CPU数据通路内部的解析执行过程；执行每条指令时，各个控制信号（Branch、RegWrite、ALUSrcB、MemtoReg等）的取值。

### 指令字段提取

- instruction[19:15] → rs1地址
- instruction[24:20] → rs2地址
- instruction[11:7] → rd地址
- instruction[31:20] → 立即数imm

### 【解题模板】指令执行过程

**add r23, r24, r25 执行过程**：
1. 取指：PC → ROM → 32位指令
2. 译码：提取rs1=24, rs2=25, rd=23
3. 读寄存器：R[24] → rdata_A, R[25] → rdata_B
4. ALU运算：rdata_A + rdata_B → result
5. 写回：result → R[23]

**lw指令执行过程**：
1. Rd_addr1 = rs1 → 读出R[rs1]
2. ALUSrcB=1 → imm送入ALU的B端口
3. ALU_op=010 → 计算 rs1+imm（地址）
4. MemWrite=0, WR=1 → 从数据存储器读数据
5. MemtoReg=1 → 存储器数据送入Wt_data
6. RegWrite=1 → 写入R[rd]

**sw指令执行过程**：
1. Rd_addr1 = rs1 → 读出R[rs1]
2. Rd_addr2 = rs2 → 读出R[rs2]
3. ALUSrcB=1 → imm送入ALU
4. ALU_op=010 → 计算地址 rs1+imm
5. MemWrite=1 → R[rs2]写入数据存储器

**sub指令执行过程**（与add类似，ALU操作不同）：
1. 取指：PC → ROM → 32位指令
2. 译码：提取rs1, rs2, rd
3. 读寄存器：R[rs1] → rdata_A, R[rs2] → rdata_B
4. ALU运算：rdata_A - rdata_B → result（ALU_op=110）
5. 写回：result → R[rd]
> ⚠️ sub的funct7=0100000，ALU_op=110（减法）

**or/and指令执行过程**（R型逻辑运算）：
1. 取指：PC → ROM → 32位指令
2. 译码：提取rs1, rs2, rd
3. 读寄存器：R[rs1] → rdata_A, R[rs2] → rdata_B
4. ALU运算：rdata_A or/and rdata_B → result（ALU_op=001/000）
5. 写回：result → R[rd]
> or的funct7=0000000, funct3=110; and的funct7=0000000, funct3=111

**beq指令执行过程**（分支跳转）：
1. 取指：PC → ROM → 32位指令
2. 译码：提取rs1, rs2
3. 读寄存器：R[rs1] → rdata_A, R[rs2] → rdata_B
4. ALU运算：rdata_A - rdata_B → 判断是否相等（ALU_op=110）
5. 若相等：PC = PC + imm×2（跳转）
6. 若不等：PC = PC + 4（顺序执行）
> beq的Branch=1，ALUSrcB=0（rs2值送入ALU），opcode=1100011

当考题给出不完整的CPU电路图时：
1. **先识别指令类型** → 确定需要哪些组件
2. **追踪数据流** → 确定缺失的连线方向
3. **检查控制信号** → 判断是否缺少控制线连接
4. **注意位宽匹配** → 补充的连线数据宽度需一致
5. **关键检查点**：
   - 寄存器堆的读写控制是否连接
   - ALU的第二操作数来源（MUX选择）
   - 写回数据的选择（MUX选择）
   - 分支地址的计算与选择
   - PC的更新逻辑

# 附录

## 考试常见错误汇总

1. **补码计算**：负数补码不是"符号位1+数值绝对值"，而是"取反加1"
2. **IEEE 754**：尾数在后面补0，阶码在前面补0
3. **小端读取**：拼接时高地址的字节是高位
4. **分支指令**：blt/bge是有符号比较，bltu/bgeu是无符号比较
5. **Cache映射**：组相联的组地址位数=log₂(组数)，不是log₂(Cache块数)
6. **溢出判断**：有符号OF=C_(n-1)⊕C_n，无符号Cout=C_n
7. **补码减法**：[-B]补是[B]补连同符号位取反加1
8. **lui范围**：lui只装高20位，addi范围-2048~2047
9. **寄存器写**：需要时钟上升沿触发；读不需要时钟
10. **CS片选**：CS=0是选中（有效），不是CS=1
11. **存储器容量**：n根地址线→2^n个单元，不是n个

## 公式速查卡

```
【数据表示】
负数补码 = 取反加1
IEEE 754：V = (-1)^S × 1.M × 2^(E-127)
数值范围：有符号 n位 → -2^(n-1) ~ 2^(n-1)-1

【定点运算】
有符号 OF = C_(n-1) ⊕ C_n
无符号 Cout = C_n
[A+B]补 = [A]补 + [B]补 (mod)
[A-B]补 = [A]补 + [-B]补

【Cache】
块内地址 b = log₂(块大小)
Cache块地址 c = log₂(Cache块数)
标记位数 = L - b - c

【存储器】
容量 = 2^n × m bits
地址范围：不变位→CS，变化位→地址端口
```
